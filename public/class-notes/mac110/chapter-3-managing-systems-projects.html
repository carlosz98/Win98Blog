Chapter 3: Managing Systems Projects

Phase 1, Systems Planning. Project management has four parts: planning (list tasks, estimate time and cost), scheduling (a timetable with dependencies), monitoring (guide the team, take corrective action) and reporting (progress updates to management, users and the team). A successful project is on time, within budget and meets requirements.

Project triangle: cost, scope and time. Change one leg and the other two move. The manager's job is finding the best balance.

The project framework, three steps:

  1. Create a work breakdown structure (WBS): every task with an estimated duration. A task (activity) has a beginning and an end and uses resources. An event (milestone) is a reference point with no duration, used to track progress.

  2. Identify task patterns: dependent tasks (B cannot start until A finishes), multiple successor tasks (several tasks start after one finishes), and multiple predecessor tasks (one task waits for several to finish), plus concurrent tasks that run at the same time.

  3. Calculate the critical path: the longest chain of dependent tasks. Tasks on it have zero slack, so any delay on them delays the whole project.

Estimating: effort is measured in person-days (what one person does in one day). The PERT weighted estimate uses best case (B), probable case (P) and worst case (W):

\text{Weighted estimate} = \frac{B + 4P + W}{6}

For example, B = 4, P = 6, W = 14 gives (4 + 24 + 14) / 6 = 7 days.

Finding the critical path by hand: a task's earliest start is the latest finish among its predecessors. Add each task's duration along every path from start to finish; the path with the largest total is the critical path, and the total is the project duration. Slack on any other task is how long it can slip without moving the end date.

Software: Microsoft Project and similar tools plan, schedule and monitor. Risk management means identifying, analyzing, anticipating and monitoring risks (risk identification, qualitative and quantitative analysis, risk response planning). Watch for Brooks' Law: adding people to a late project makes it later.

Likely test points

  • Draw or read a Gantt chart and a PERT chart; find the critical path and slack.

  • Compute a weighted (B + 4P + W) / 6 estimate.

  • The three legs of the project triangle and what happens when one changes.

  • Task vs. event (milestone); the three task patterns.

  • The four project management activities: plan, schedule, monitor, report.
