MAC 110 - SYSTEMS ANALYSIS AND DESIGN

The big picture

The whole book (Tilley and Rosenblatt, Systems Analysis and Design, 11th edition) follows one idea: the systems development life cycle (SDLC), five phases that take a system from an idea to something running and supported. Every chapter belongs to one phase, so if you know which phase a topic lives in, you know where it fits.

How to study with this guide. Each chapter section below has the main ideas, the key terms in a table, the models explained in words, and a short list of likely test points. Definitions follow the book's own key-terms lists so they match what the test will ask. Finish with the review section at the end, which pulls the most testable items together.

Three development approaches run through every chapter:

  • Structured analysis is the traditional, predictive method. It uses the SDLC as a waterfall model (each phase finishes before the next) and models the system with data flow diagrams.

  • Object-oriented (O-O) analysis combines data and the processes that act on it into objects. Phases are similar to the SDLC but more interactive. It is modeled with UML.

  • Agile (adaptive) methods build the system in small pieces through a spiral model of iterations and prototypes, adjusting to user feedback each round.
