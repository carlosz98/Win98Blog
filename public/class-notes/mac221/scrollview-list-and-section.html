ScrollView, List and Section

ScrollView scrolls any content that's bigger than the screen; List is a ready-made scrolling table of rows; Section groups rows under a header inside a List or Form.

ScrollView

It scrolls vertically by default. Pass .horizontal, or [.horizontal, .vertical] for both.

ScrollView {                                     // vertical
    VStack(spacing: 20) {
        ForEach(1...20, id: \.self) { index in
            Text("Item \(index)")
                .frame(width: 300, height: 50)
                .background(Color.blue)
                .foregroundColor(.white)
                .cornerRadius(10)
        }
    }
    .padding()
}

ScrollView(.horizontal) {                        // horizontal needs an HStack inside
    HStack(spacing: 20) { /* ForEach ... */ }
}

ScrollView([.horizontal, .vertical]) {           // a grid you can pan both ways
    VStack {
        ForEach(1...10, id: \.self) { row in
            HStack {
                ForEach(1...10, id: \.self) { column in
                    Text("R\(row)C\(column)")
                }
            }
        }
    }
}
CustomizationCode
Hide the scroll barScrollView(showsIndicators: false) (default is true)
Size of the scroll area.frame(width: 350, height: 400) on the ScrollView
Space around / between items.padding(), VStack(spacing:)

Section

List {
    Section(header: Text("Section 1")) {
        Text("Item 1")
        Text("Item 2")
    }
    Section(header: Text("Section 2")) {
        Text("Item 3")
        Text("Item 4")
    }
}

The contact form example uses Form with two sections: text fields in one, buttons in the other.

@State private var name = ""
@State private var email = ""
@State private var phoneNumber = ""

Form {
    Section(header: Text("Personal Information")) {
        TextField("Name", text: $name)              // "Name" is the placeholder
        TextField("Email", text: $email)
        TextField("Phone Number", text: $phoneNumber)
    }
    Section(header: Text("Actions")) {
        Button("Save Contact") { /* save */ }
        Button("Delete Contact") { /* delete */ }
    }
}

Section headers can be styled like any Text (.background(Color.blue).foregroundColor(.white)), and rows can get .padding(), .cornerRadius(10) and .shadow(radius: 5).

ScrollView vs List: List gives you rows, separators, swipe and selection for free and only builds rows on screen. ScrollView is plain, so you lay out everything yourself, but it can scroll sideways.
