Swift Basics

Swift code is variables, conditions, loops, functions and classes. The class practiced all of it in an Xcode Playground (File > New > Playground), which runs code line by line and shows results on the right.

Variables and constants

  • var makes a variable (can change). let makes a constant (assigned exactly once).

  • Reassigning a let is a compile error: "Cannot assign to value: 'lastname' is a 'let' constant".

  • Name things in camelCase (firstName, stockPrice).

  • Swift infers the type from the first value. Write the type after a colon when there's no value or you want a different type.

  • Values are never converted for you. Convert explicitly, for example String(width).

var myVariable = 42
myVariable = 50          // fine
let myConstant = 42      // can't change later

let implicitDouble = 70.0
let explicitDouble: Double = 70
var firstName: String = "Tom"

let label = "The width is "
let width = 94
let widthLabel = label + String(width)   // must convert Int to String

String interpolation puts a value inside text: "My favorite is \(name)".

If, else if, else

Swift checks conditions top to bottom and runs only the first one that's true. else runs when none are.

let a = 25
let b = 10

if a <= 10 || b > 5 {        // || means OR, && means AND, != means not equal
    print("branch 1")
} else if a < 15 {
    print("branch 2")
} else if a > 30 {
    print("branch 3")
} else {
    print("catch all")
}
// prints "branch 1"

Switch

switch compares one value against several cases and runs the first match. It must be exhaustive, so you usually need default. Every case needs at least one statement, there's no fall-through, and one case can list several values or a range.

let someCharacter: Character = "a"
switch someCharacter {
case "a", "A":               // compound case
    print("The letter A")
default:
    print("Not the letter A")
}

let approximateCount = 62
switch approximateCount {
case 0:         print("no")
case 1..<5:     print("a few")      // ..< excludes the top number
case 12..<100:  print("dozens of")
default:        print("many")
}

Loops

for counter in 1...5 {        // ... includes 5, so it runs 5 times
    print(counter)
}

var sum = 0
for counter in 1...5 { sum += counter }
print(sum)                     // 15

var count = 5
while count > 0 {              // checks first; may run 0 times
    print("Hello")
    count -= 1                 // forget this and it loops forever
}

var n = -5
repeat {                       // runs once before checking
    print("HELLO")
    n -= 1
} while n > 0                  // prints HELLO once

Functions

A function is a named block of code you run by calling its name. Variables made inside a function exist only inside it (scope).

func addTwoNumbers() -> Int {          // -> Int is the return type
    let a = 1, b = 2
    return a + b
}
let sum = addTwoNumbers()

func favoriteAlbum(name: String) {     // parameter
    print("My favorite is \(name)")
}
favoriteAlbum(name: "Fearless")

func countLetters(in string: String) { // "in" is the argument label, "string" the parameter name
    print("\(string) has \(string.count) letters")
}
countLetters(in: "Hello")

func shout(_ text: String) { print(text) }   // _ means no label when calling
shout("Hi")

func printAlbumRelease(name: String, year: Int) {
    print("\(name) was released in \(year)")
}
printAlbumRelease(name: "Fearless", year: 2008)

Classes, objects and inheritance

A class is a blueprint. An object is one actual instance made from it. Properties are its variables and methods are its functions.

class Employee {
    var name = ""
    var salary = 0
    var role = ""

    func doWork() {
        print("Hi my name is \(name) and I'm doing work")
        salary += 1
    }
}

var c = Employee()       // create an object
c.name = "Tom"
c.doWork()

class Manager: Employee {           // Manager inherits everything from Employee
    var teamSize = 0                // and adds its own property

    override func doWork() {        // replace the parent's version
        super.doWork()              // still run the parent's version first
        print("I'm managing people")
        salary += 2
    }
}

  • Employee is the superclass (parent); Manager is the subclass (child).

  • override is required to replace an inherited method; super calls the parent's version.

Optionals hold either a value or nil (nothing). Mark one with ? after the type.

var index: Int?                       // starts as nil
index = 2

if let i = index {                    // optional binding: safe unwrap
    print(treeArray[i])
}
print(index!)                         // forced unwrap: crashes if nil
let safe = index ?? 0                 // nil-coalescing: use 0 if nil

Structs vs classes: a struct is a value type (assigning it makes a copy), and a class is a reference type (assigning shares the same object). Only classes have inheritance. SwiftUI views are structs; ObservableObject must be a class.

Arrays and dictionaries: var trees = ["Pine", "Oak"], trees.append("Yew"), trees.count; var ages = ["Tom": 25], ages["Tom"] returns an optional.

Closures are unnamed functions you can pass around, like the { ... } after Button("Tap") or .onAppear { ... }.
