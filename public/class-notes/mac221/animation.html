Animation

SwiftUI animates by changing a @State value; the animation smoothly moves the view from the old value to the new one. There are two ways to ask for it: implicit (.animation(...) on the view) and explicit (withAnimation { ... } around the state change).

Basic: scale a button

struct ContentView: View {
    @State private var scale = 1.0

    var body: some View {
        Button("Press here") {
            scale += 1
        }
        .scaleEffect(scale)                                   // 1.0 = normal, 2.0 = double, 0.5 = half
        .animation(.linear(duration: 1), value: scale)        // animate whenever scale changes
    }
}

  • value: scale is the trigger: the animation only runs when that value changes. The older form without value: (.animation(.linear(duration: 1))) is deprecated but still shows up in the slides.

  • Every press grows the button by 1.0, smoothly, over 1 second.

Animation types

AnimationFeels like
.linear(duration: 1)Constant speed
.easeInStarts slow, speeds up
.easeOutStarts fast, slows down
.easeInOut(duration: 1)Slow, fast, slow
.spring()Overshoots and bounces back
.interpolatingSpring(mass: 1, stiffness: 1, damping: 0.5, initialVelocity: 10)A custom spring
.defaultThe system default

Rotate and thicken a border at the same time:

@State private var angle = 0.0
@State private var borderThickness = 1.0

Button("Press here") {
    angle += 45
    borderThickness += 1
}
.padding()
.border(.red, width: borderThickness)
.rotationEffect(.degrees(angle))
.animation(.easeIn, value: angle)

Start an animation when a view appears (repeat forever)

@State var scale = 1.0

Circle()
    .frame(width: 200, height: 200)
    .scaleEffect(scale)
    .onAppear {
        let baseAnimation = Animation.easeInOut(duration: 1)
        let repeated = baseAnimation.repeatForever(autoreverses: true)
        withAnimation(repeated) {
            scale = 0.5          // pulses between 1.0 and 0.5 forever
        }
    }

Several animations on one view

An .animation modifier only covers the modifiers above it. Use nil to switch animation off for one part.

Button("Press Me") { isEnabled.toggle() }
    .foregroundStyle(.white)
    .frame(width: 200, height: 200)
    .background(isEnabled ? .green : .red)
    .animation(nil, value: isEnabled)          // color changes instantly
    .clipShape(RoundedRectangle(cornerRadius: isEnabled ? 100 : 0))
    .animation(.default, value: isEnabled)     // shape change is animated

Transitions: animate views being added and removed

A transition controls how a view enters and leaves when an if shows or hides it. It needs an animation to go with it, usually withAnimation.

@State private var showDetails = false

VStack {
    Button("Press to show Courses") {
        withAnimation(.easeInOut(duration: 0.5)) {      // explicit animation
            showDetails.toggle()
        }
    }
    if showDetails {
        Text("MAC 221").transition(.move(edge: .bottom))   // slides up from the bottom
        Text("MAC 280").transition(.slide)                 // in from leading, out to trailing
        Text("MAC 250").transition(.scale)                 // grows from small
        Text("Hello").transition(.opacity)                 // fades in and out
    }
}

The same idea works with a Toggle bound to showingWelcome: wrap the shown Text in .transition(.opacity).
