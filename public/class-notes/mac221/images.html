Images

To use your own picture, drag it into Assets.xcassets in Xcode, then load it by its asset name with Image("ocean"). SF Symbols (Apple's built-in icons) load with Image(systemName: "trash").

A plain Image("ocean") shows at its original size, so a large photo runs past the screen and only part of it is visible. Add .resizable() first, then choose how it scales.

Image("ocean")
    .resizable()          // must come first, or the scaling modifiers do nothing
    .scaledToFit()        // whole image visible, may leave empty space

Image("puppies")
    .resizable()
    .scaledToFill()       // fills the space, may crop the edges
    .frame(width: 300, height: 300, alignment: .leading)
    .clipped()            // cut off whatever falls outside the frame

Image("logo")
    .resizable(resizingMode: .tile)   // repeat the image like wallpaper
ModifierWhat it does
.resizable()Lets the image be scaled up or down
.scaledToFit() / .aspectRatio(contentMode: .fit)Fit inside the space, keep proportions, no cropping
.scaledToFill() / .aspectRatio(contentMode: .fill)Fill the space, keep proportions, may crop
.frame(width:height:alignment:)Set the size
.clipped()Hide anything outside the frame
.clipShape(Circle())Cut the image into a shape

SF Symbols behave like text, so you size them with .font and color them with .foregroundStyle or .foregroundColor:

Image(systemName: "cloud.sun.rain.fill")
    .font(.largeTitle)
    .foregroundStyle(.red)

Image(systemName: "cloud.sun.rain.fill")
    .renderingMode(.original)   // use the symbol's own multicolor
    .font(.largeTitle)
    .padding()
    .background(.black)
    .clipShape(Circle())
