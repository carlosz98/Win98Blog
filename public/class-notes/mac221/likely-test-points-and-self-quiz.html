Likely test points and self-quiz

These are the ideas the slides spend the most time on or explain line by line, so they're the most likely to be tested.

Know cold

  1. var vs let, and the error you get reassigning a let.

  2. The five basic types (String, Int, Float, Double, Bool) and that Swift never converts types for you (String(width)).

  3. 1...5 (includes 5) vs 1..<5 (stops at 4); while vs repeat-while (runs at least once).

  4. switch must be exhaustive, needs default unless every case is covered, and has no fall-through.

  5. Function syntax: argument labels, _ to drop a label, -> Type return.

  6. Class vs object; subclass with class Manager: Employee; override and super.

  7. What each line of the starter ContentView does (import SwiftUI, struct ... : View, var body: some View, the Previews struct).

  8. VStack / HStack / ZStack: direction, default alignment (.center), and that ZStack has no spacing.

  9. Modifier order changes the result.

  10. Image needs .resizable() before .scaledToFit() / .scaledToFill(); .clipped() crops; SF Symbols use systemName:.

  11. @State + $ binding; .toggle() on a Bool.

  12. Picker: selection binding, .tag() type must match the state type; the four styles (menu, wheel, segmented, navigation link).

  13. DatePicker: selection: $date, displayedComponents: .date, wheel / graphical / compact styles, DateFormatter.dateStyle outputs.

  14. ScrollView default direction (vertical), .horizontal, both axes, showsIndicators: false.

  15. List(items, id: \.self) for Strings vs Identifiable + let id = UUID() for structs.

  16. NavigationView + NavigationLink(destination:), and putting .navigationBarTitle on the inner content.

  17. Enum with String, CaseIterable, Identifiable feeding a Picker through allCases.

  18. ObservableObject (class) + @Published + @ObservedObject; @EnvironmentObject injected with .environmentObject() in the App struct; ObservableObject comes from Combine.

  19. .animation(_:value:) vs withAnimation { }; easeIn / easeOut / linear / spring; .transition(.slide / .scale / .opacity / .move(edge:)).

  20. API pattern: Codable model, URLSession.shared.dataTask, JSONDecoder().decode([T].self, from:), DispatchQueue.main.async, .resume(), fetch in .onAppear.

Self-quiz

Try each one before reading the answer under it.

  1. What prints? var sum = 0; for i in 1...5 { sum += i }; print(sum)

    • 15

  2. var count = -5; repeat { print("HI"); count -= 1 } while count > 0. How many times does HI print?

    • Once. repeat-while runs before checking.

  3. Why does let name = "Tom"; name = "Sam" fail?

    • name is a constant; a let can be assigned only once.

  4. Which stack layers views on top of each other?

    • ZStack. The first child is at the back.

  5. Your image runs off the screen. What two modifiers fix it?

    • .resizable() then .scaledToFit().

  6. What does the $ in Toggle("Wi-Fi", isOn: $isOn) mean?

    • It passes a binding, so the toggle can change the @State value.

  7. Your Picker never changes the selection. The state is @State var option = 1 and options are .tag("1"). Why?

    • Tag type (String) doesn't match the state type (Int).

  8. Which picker style shows options as a bar of buttons?

    • Segmented, .pickerStyle(SegmentedPickerStyle()).

  9. What does CaseIterable add to an enum?

    • allCases, an array of every case.

  10. Why does a List of a custom struct need Identifiable?

    • So SwiftUI can tell rows apart; usually let id = UUID().

  11. Difference between @ObservedObject and @EnvironmentObject?

    • ObservedObject is created or passed into one view; EnvironmentObject is injected once with .environmentObject() and read by any view below.

  12. What does @Published do?

    • Announces changes to that property so watching views redraw.

  13. In the API example, why is the result assigned inside DispatchQueue.main.async?

    • The network call finishes on a background thread, and UI updates must happen on the main thread.

  14. What happens if you forget .resume() on a data task?

    • The request never starts.

  15. Which animation overshoots and bounces?

    • .spring().

  16. How do you make a view pulse forever as soon as it appears?

    • In .onAppear, withAnimation(Animation.easeInOut(duration: 1).repeatForever(autoreverses: true)) { scale = 0.5 }.

  17. Name the four transitions from the slides.

    • .opacity, .slide, .scale, .move(edge: .bottom).

  18. What's the difference between .scaledToFit() and .scaledToFill()?

    • Fit shows the whole image (may leave gaps); Fill covers the space (may crop).
