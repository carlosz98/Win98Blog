SwiftUI fundamentals and Stacks

Every SwiftUI screen is a struct that conforms to View and returns its layout from body. Layout is built by nesting stacks and chaining modifiers.

The starter file (from the App Development Overview)

New project: Xcode > Create a new Xcode project > iOS > App, with Interface set to SwiftUI and Language set to Swift. You run it in the Simulator or see it live in the Canvas preview.

import SwiftUI                         // brings in the SwiftUI framework

struct ContentView: View {             // a struct that conforms to the View protocol
    var body: some View {              // computed property; "some View" = returns one kind of View without naming it
        Text("Hello, World!")          // a Text view
            .padding()                 // a modifier: adds space around it
    }
}

struct ContentView_Previews: PreviewProvider {   // draws the Canvas preview
    static var previews: some View {
        ContentView()
    }
}

  • A modifier (.padding(), .font(.title), .background(...)) returns a new, changed view. Order matters: .padding().background(.purple) colors the padded area, while .background(.purple).padding() colors only behind the text.

  • You can add modifiers visually: the Attributes inspector (Font, Weight, Color, Alignment, Padding), the Library (+) to search modifiers, or Cmd-click a view for Embed in HStack / VStack / List, Extract Subview, and so on.

The three stacks

StackArranges childrenAlignment optionsSpacing?
VStackTop to bottom.leading, .center (default), .trailingYes
HStackLeft to right.top, .center (default), .bottom, .firstTextBaseline, .lastTextBaselineYes
ZStackBack to front (layered, first child is at the back).center (default), .top, .bottom, .leading, .trailing, .topLeading, .bottomTrailing, etc.No

Alignment and spacing are both optional. Spacing is in points.

VStack(alignment: .leading, spacing: 10) {
    Text("VStack").font(.title)
    Text("Spacing & Alignment").font(.subheadline)
}

HStack(spacing: 10) {
    Circle().fill(.blue).frame(width: 100, height: 100)
    Rectangle().fill(.yellow).frame(width: 100, height: 100)
    Capsule().fill(.orange).frame(width: 100, height: 50)
}

ZStack {
    Circle().fill(.blue).frame(width: 200, height: 200)          // back
    Capsule().fill(Color.white.opacity(0.5)).frame(width: 190, height: 50)
    Text("Hello World!").foregroundColor(.white)                // front
}

Spacer() takes up all free space, pushing views apart (two Spacers around a view center it). .frame(maxWidth: .infinity) stretches a view across the screen.

Practice: the Contact card

VStack {
    Text("Contact example").font(.title)
    Spacer()
    ZStack {                                   // initials on a circle
        Circle().fill(.orange).frame(width: 150, height: 150)
        Text("JD")
            .foregroundColor(.white)
            .font(.system(size: 75, weight: .bold))
    }
    Text("John Doe").font(.title)
    Text("SwiftUI Engineer").font(.subheadline)
    HStack(spacing: 20) {                      // two buttons side by side
        Button(action: {}) {
            VStack { Image(systemName: "message"); Text("message") }
                .frame(minWidth: 70)
                .padding()
                .foregroundColor(.white)
                .background(.blue)
                .cornerRadius(8)
        }
        // same again with "phone" / "call"
    }
    Spacer()
}
