Everything from opening Apache to writing our first working script, start to finish:

<?php
echo "Hello Student MAC272";
?>

Clean formatting: newline right after the opening <?php, newline after the echo statement, and the closing ?> on its own line.

How to run it:

  1. Open the XAMPP Control Panel and click Start next to Apache.

  2. Create a new text document in the code editor (using VS Code).

  3. Write the code: <?php echo "Hello Student of MAC272"; ?>

  4. Save as index.php.

  5. Save it inside the XAMPP folder, in htdocs.

  6. Create a project folder (e.g. MAC272) inside htdocs and save/drag the file there.

  7. With Apache running (started in XAMPP), go to the browser and enter localhost/MAC272/ — since index.php is the default file, it loads automatically and shows the PHP output.

Default Entry File

By default, index.php is the page a web server loads first when you visit a folder — similar to how main is the entry point in Java or C++. In PHP, that entry point is index.

Starting Apache on Mac (XAMPP-VM)

On Mac, XAMPP's Welcome screen doesn't have a single Start button like Windows — Apache is started from the Manage Servers tab instead:

  1. Click Manage Servers at the top of the window.

  2. Find Apache Web Server in the list and click Start.

  3. On Mac, the web root (htdocs) is at /Applications/XAMPP/xamppfiles/htdocs — or use Open Application Folder from the Welcome tab to get there.

Variables

In PHP, a variable starts with $ followed by a name, and is assigned with =. Variables inside a double-quoted string are automatically interpolated (their value gets inserted right into the string):

<?php
echo "Hello Students of Mac272";
$name = "Carlos";
echo "Hello my name is $name";
?>

To put the second line on its own line: in HTML output, a plain \n won't visually break the line — browsers collapse whitespace. Use an actual HTML line break, <br>:

<?php
echo "Hello Students of Mac272<br>";
$name = "Carlos";
echo "Hello my name is $name";
?>

(Alternatively, wrap each echo in <p>...</p> tags for separate paragraphs.)

Single Quotes vs. Double Quotes (Concatenation)

  • Double quotes ("...") — PHP interpolates variables automatically, e.g. "Hello my name is $name" inserts the value of $name directly.

  • Single quotes ('...') — treated literally, no interpolation. $name inside single quotes prints as the literal text $name, not its value.

To include a variable's value in a single-quoted string, break out and concatenate with the . operator:

<?php
$name = "Carlos";
echo 'Hello ' . $name . ' How are you today?';
?>

(Watch spacing: .$name. with no space inside the quotes prints everything mashed together, e.g. HelloCarlosHow are you today?. Add spaces inside the quotes, as above, to separate the words.)

Comments

Comments are ignored when the code runs — useful for notes to yourself or your team. PHP supports two styles:

  • Single-line: // comment text

  • Multi-line: /* ... */, can span several lines

// This is a single line comment

/* This is
multi
line
comment
*/

Conditional Statements (if / else)

An if statement runs a block of code only when a condition is true; else runs when it's false.

$number = 18;
if ($number > 10) {
    echo "The number is greater than 10<br>";
} else {
    echo "The number is less than 10";
}

  • The condition goes inside parentheses ( ); the code to run goes inside curly braces { }.

  • Common comparison operators: >, <, >=, <=, ==, !=.
