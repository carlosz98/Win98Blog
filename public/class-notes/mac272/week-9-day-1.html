Week 9, Day 1 — Tuesday 11/17/2026: Assignment 3 (Search and Feedback with MySQL)

Assignment 3 (100 points):

  1. Search page: create a users table, insert some rows, and make a PHP page that searches it with a LIKE query (partial matching of names).

  2. Feedback page: a form (name, email, feedback, Send Feedback) that saves everything into a feedback table.

Three files: setup.php (run once), search.php, feedback.php. Only things from class: mysqli procedural, forms, validation, and the Part 10 prepared statement.

The order (always the same with a database):

  1. Start Apache and MySQL in XAMPP. Nothing connects without MySQL running.

  2. Create the database (CREATE DATABASE): connect with 3 arguments, because the database doesn't exist yet.

  3. Create the tables (CREATE TABLE): connect with 4 arguments, now that the database exists. Tables go inside a database.

  4. Insert the data (INSERT INTO): rows go inside a table, so the table must exist first.

  5. Use the pages: search (SELECT ... LIKE) and feedback (INSERT from the form).

  6. Check the data in phpMyAdmin.

Steps 2–4 are all in setup.php, in that order. Doing them out of order gives Unknown database or Table doesn't exist.

Part 2: feedback.php

<?php
$message = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $name = trim($_POST["name"]);
    $email = trim($_POST["email"]);
    $feedback = trim($_POST["feedback"]);

    if (empty($name) || empty($email) || empty($feedback)) {
        $message = "Please fill in all the fields.";
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $message = "Please enter a valid email address.";
    } else {
        // prepared statement, same as the Part 10 handout
        $conn = new mysqli("localhost", "root", "", "Assignment3DB");
        if ($conn->connect_error) {
            die("Connection failed: " . $conn->connect_error);
        }

        $stmt = $conn->prepare("INSERT INTO feedback (name, email, message) VALUES (?, ?, ?)");
        $stmt->bind_param("sss", $name, $email, $feedback);

        if ($stmt->execute()) {
            $message = "Thank you! Your feedback was saved.";
        } else {
            $message = "Error: " . $stmt->error;
        }

        $stmt->close();
        $conn->close();
    }
}

Why it's written this way

  • LIKE '%$search%': % means "anything here", so on both sides it finds the text anywhere in the name (partial match). Inside double quotes, $search is replaced by what the user typed.

  • Search uses GET (can be bookmarked, changes nothing). Feedback uses POST (saves data).

  • Feedback uses the Part 10 prepared statement (prepare, bind_param("sss", ...), execute). Why: feedback is free text, and an apostrophe like It's great would break a normal '$feedback' INSERT. With ? the text is sent separately, so any characters work and SQL injection is blocked.

  • Validation from Lesson 8: trim(), empty() and filter_var(..., FILTER_VALIDATE_EMAIL) before saving.

  • htmlspecialchars() when printing the search term back on the page.

Lab: PHP MySQL Login System (CollegeLoginDB, 100 points)

Register, log in, see a protected welcome page, remember the username with a cookie, and log out. Uses everything so far: forms (POST), MySQL, prepared statements, sessions and cookies. New today: password_hash() / password_verify() and session_regenerate_id().

🆕 NEW in this lab (not covered in class before), required by the lab:

  • password_hash($password, PASSWORD_DEFAULT): turns a password into a hash to store.

  • password_verify($typed, $hash): checks a typed password against that hash.

  • session_regenerate_id(true): a new session ID at login.

  • setcookie(name, value, [ "expires" => ..., "path" => ..., "httponly" => true, "samesite" => "Lax" ]): setcookie with an options array.

  • $stmt->get_result(), $result->num_rows, $result->fetch_assoc(): reading rows from a prepared SELECT (Part 10 only showed INSERT).

  • session_name(): the session cookie's name (PHPSESSID), used to delete it at logout.

  • Bonus only: <input type="checkbox">, which is sent only when checked, so PHP checks it with isset($_POST["remember"]).

Everything else is from class: mysqli, forms with POST, trim()/empty(), sessions, cookies, header() + exit, htmlspecialchars().

insert_user.php

<?php
// 1. Connect to CollegeLoginDB
$conn = new mysqli("localhost", "root", "", "CollegeLoginDB");
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}

// 2. Read the form values
$username = trim($_POST["username"]);
$email = trim($_POST["email"]);
$password = $_POST["password"];

// 3. No blank fields
if (empty($username) || empty($email) || empty($password)) {
    echo "All fields are required.";
} else {
    // Is the username already taken?
    $stmt = $conn->prepare("SELECT id FROM Users WHERE username = ?");
    $stmt->bind_param("s", $username);
    $stmt->execute();
    $result = $stmt->get_result();

    if ($result->num_rows > 0) {
        echo "Username already exists.";
    } else {
        // 4. Hash the password
        $hashed = password_hash($password, PASSWORD_DEFAULT);

        // 5. Insert with a prepared statement
        $stmt = $conn->prepare("INSERT INTO Users (username, email, password) VALUES (?, ?, ?)");
        $stmt->bind_param("sss", $username, $email, $hashed);

        // 6. Message
        if ($stmt->execute()) {
            echo "Registration successful!";
        } else {
            echo "Error: " . $stmt->error;
        }
    }
    $stmt->close();
}

$conn->close();
?>
<p><a href="login.html">Go to login</a></p>

  • Why check the username first: in PHP 8 a duplicate INSERT on a UNIQUE column stops the page with a fatal error. Checking with SELECT first lets us print Username already exists.

  • get_result() turns the prepared SELECT into a normal result, so num_rows and fetch_assoc() work like in class.

  • password_hash() saves something like $2y$10$... (60 characters), never the real password.

login.php (Tasks 6, 7 and 9)

<?php
session_start();

// 1. Connect
$conn = new mysqli("localhost", "root", "", "CollegeLoginDB");
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}

// 2. Read the form values
$username = trim($_POST["username"]);
$password = $_POST["password"];

// 3. Find the user by username (prepared statement)
$stmt = $conn->prepare("SELECT username, password FROM Users WHERE username = ?");
$stmt->bind_param("s", $username);
$stmt->execute();
$result = $stmt->get_result();
$user = $result->fetch_assoc();

$stmt->close();
$conn->close();

// 4. Check the password against the hash
if ($user && password_verify($password, $user["password"])) {
    // Session (Task 7)
    session_regenerate_id(true);
    $_SESSION["username"] = $user["username"];

    // Cookie for 7 days (Task 9)
    setcookie("remember_user", $user["username"], [
        "expires" => time() + (7 * 24 * 60 * 60),
        "path" => "/",
        "httponly" => true,
        "samesite" => "Lax"
    ]);

    header("Location: welcome.php");
    exit;
} else {
    echo "Invalid username or password.";
    echo '<p><a href="login.html">Try again</a></p>';
}
?>

  • password_verify(typed, hash) checks the typed password against the saved hash. You can't compare with == because the hash is not the password.

  • $user &&: if the username doesn't exist, fetch_assoc() gives NULL, so it goes to the error. The same message for a wrong username or wrong password doesn't tell attackers which one was right.

  • session_regenerate_id(true) gives a new session ID at login (stops session fixation).

  • Cookie options: httponly (JavaScript can't read it), samesite (not sent from other sites). 7 * 24 * 60 * 60 = 7 days in seconds. Only the username, never the password.

  • setcookie() and header() run before any HTML, as always.

logout.php

<?php
session_start();

// 1. Clear all session variables
session_unset();

// 2. Delete the session cookie (PHPSESSID)
setcookie(session_name(), "", time() - 3600, "/");

// 3. Destroy the session
session_destroy();

// remember_user is kept on purpose (only the username, not a login)
header("Location: login.html");
exit;
?>

session_name() is PHPSESSID; setting it in the past deletes the session cookie from the browser.
