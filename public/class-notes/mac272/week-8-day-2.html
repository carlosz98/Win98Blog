The pattern every example uses

<?php
$servername = "localhost";
$username = "root";
$password = "";
$dbname = "myDB";

// 1. connect
$conn = mysqli_connect($servername, $username, $password, $dbname);
if (!$conn) {
    die("Connection failed: " . mysqli_connect_error());
}

// 2. run the SQL
$sql = "...";
if (mysqli_query($conn, $sql)) {
    echo "Success";
} else {
    echo "Error: " . mysqli_error($conn);
}

// 3. close
mysqli_close($conn);
?>

  • mysqli_connect(host, user, password, database): on XAMPP the user is usually root with an empty password.

  • die() prints the message and stops the script.

  • To create a database, connect with only the first three arguments (no database yet).

Insert

Rules: the SQL is in quotes in PHP, string values inside it use single quotes, numbers and NULL have no quotes. You don't give id or reg_date; MySQL fills them.

$sql = "INSERT INTO MyGuests (firstname, lastname, email)
VALUES ('John', 'Doe', 'john@example.com')";
if (mysqli_query($conn, $sql)) {
    $last_id = mysqli_insert_id($conn);
    echo "New record created successfully. Last inserted ID is: " . $last_id;
}

Output: New record created successfully. Last inserted ID is: 1

Several inserts at once: join them with ; and use mysqli_multi_query():

$sql = "INSERT INTO MyGuests (firstname, lastname, email) VALUES ('Mary', 'Moe', 'mary@example.com');";
$sql .= "INSERT INTO MyGuests (firstname, lastname, email) VALUES ('Julie', 'Dooley', 'julie@example.com')";
mysqli_multi_query($conn, $sql);

Select (with WHERE and ORDER BY)

$sql = "SELECT id, firstname, lastname FROM MyGuests";
$result = mysqli_query($conn, $sql);

if (mysqli_num_rows($result) > 0) {
    while ($row = mysqli_fetch_assoc($result)) {
        echo "id: " . $row["id"] . " - Name: " . $row["firstname"] . " " . $row["lastname"] . "<br>";
    }
} else {
    echo "0 results";
}

  • mysqli_fetch_assoc() gives one row as an associative array ($row["firstname"]), and NULL when there are no more rows, which ends the while loop.

  • SELECT * selects all columns.

Update and delete

$sql = "UPDATE MyGuests SET lastname='Doe' WHERE id=2";   // Record updated successfully
$sql = "DELETE FROM MyGuests WHERE id=3";                // Record deleted successfully

Always use WHERE. Without it, UPDATE changes every row and DELETE removes every row.

Prepared statements

The SQL is sent once with ? in place of the values; the values are sent separately. Faster when repeated, and it protects against SQL injection. The handout writes this one in object-oriented style:

$conn = new mysqli($servername, $username, $password, $dbname);
$stmt = $conn->prepare("INSERT INTO MyGuests (firstname, lastname, email) VALUES (?, ?, ?)");
$stmt->bind_param("sss", $firstname, $lastname, $email);

$firstname = "John"; $lastname = "Doe"; $email = "john@example.com";
$stmt->execute();

$firstname = "Mary"; $lastname = "Moe"; $email = "mary@example.com";
$stmt->execute();

$stmt->close();
$conn->close();

"sss" = one letter per ?: i integer, d double, s string, b BLOB.
