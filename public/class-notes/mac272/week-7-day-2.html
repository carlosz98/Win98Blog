Week 7, Day 2 — Thursday 11/05/2026: Midterm Exam (coding questions)

The coding part of the midterm: a 2D array with loops, a function, and the login (form + PHP + welcome page). Every answer below was run in PHP 8.3.

1. Two-dimensional array: students and grades

<?php
$students = [
    ["Ali", "Sara", "Omar"],
    [85, 90, 78]
];

for ($i = 0; $i < count($students); $i++) {
    for ($j = 0; $j < count($students[$i]); $j++) {
    }
    echo "<br>";
}

echo "<br>";

for ($j = 0; $j < count($students[0]); $j++) {
    echo "Student: " . $students[0][$j] . ", Grade: " . $students[1][$j] . "<br>";
}
?>

Output: three empty lines, then:

Student: Ali, Grade: 85
Student: Sara, Grade: 90
Student: Omar, Grade: 78

  • Row 0 has the names and row 1 the grades. The same column is the same student: $students[0][1] is Sara and $students[1][1] is 90.

  • count($students) is 2 (rows); count($students[0]) is 3 (items in row 0).

  • The nested loops have an empty inner body, so they only print one <br> per row (2), plus the echo "<br>"; after them = 3 empty lines.

  • The last loop uses one $j to read the name and the grade from the same column.

To print every value with the nested loops, put the echo inside the inner braces:

for ($i = 0; $i < count($students); $i++) {
    for ($j = 0; $j < count($students[$i]); $j++) {
        echo $students[$i][$j] . " ";
    }
    echo "<br>";
}
// Ali Sara Omar
// 85 90 78

2. Function: Celsius to Fahrenheit

<?php
function convertTemp($c) {
    $f = ($c * 9 / 5) + 32;
    return $f;
}
echo "The conversion from C to F of 20C: " . convertTemp(20) . "F";
?>

Output: The conversion from C to F of 20C: 68F

  • Formula: F = C × 9 / 5 + 32. For 20: 20 × 9 = 180, / 5 = 36, + 32 = 68.

  • $c is the parameter, 20 is the argument. $f is local, so it only gets out with return.

  • Other values: convertTemp(0) = 32, convertTemp(100) = 212, convertTemp(37) = 98.6.

3. Login page: login.html

<!DOCTYPE html>
<html lang="en">
<head>
<title>Login</title>
</head>
<body>
    <h2>Login</h2>
    <form action="process_login.php" method="post">
        <label for="username">Username:</label>
        <input type="text" id="username" name="username"><br><br>
        <label for="password">Password</label>
        <input type="password" id="password" name="password"><br><br>
        <input type="submit" value="Login" name="submit">
    </form>
</body>
</html>

  • action sends the data to process_login.php; method="post" keeps it out of the URL.

  • PHP reads each box by its name: $_POST["username"], $_POST["password"]. The id only links the label.

4. process_login.php and welcome.php

<?php
$username = trim($_POST["username"]);
$password = trim($_POST["password"]);

$usernames = ["carlos", "carolina"];
$passwords = ["123", "456"];

$found = false;
for ($i = 0; $i < count($usernames); $i++) {
    if ($username == $usernames[$i] && $password == $passwords[$i]) {
        $found = true;
        break;
    }
}

if ($found) {
    header("Location: welcome.php");
    exit;
} else {
    echo "Username and password incorrect";
}
?>
<!-- welcome.php -->
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Welcome</title>
</head>
<body>
    <h1>Welcome!</h1>
</body>
</html>

carolina / 456Redirects to welcome.php: Welcome!
carlos / 456Username and password incorrect (456 is carolina's)

  • Read, arrays, loop, decide: the same pattern as the Midterm Review Q4.

  • Both values must match at the same index, and trim() removes extra spaces before checking.

  • Put the three files in one folder in htdocs and open http://localhost/<folder>/login.html.
