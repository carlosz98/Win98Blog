Lesson 1 — Introduction (PHP Tutorial Part 1)

Big idea: PHP runs on the server, talks to MySQL for data, and sends only HTML to the browser.

Key terms

TermWhat to remember
PHPHypertext Preprocessor. Server-side scripting language for dynamic web pages.
MySQLOpen-source relational database (RDBMS): tables of rows and columns, queried with SQL.
MariaDBAn open-source fork of MySQL; replaces it in many XAMPP versions.
ApacheThe web server. Receives requests and passes .php files to PHP.
PHP parser (module)Reads and runs the PHP code on the server; built into Apache.

PHP: 8 key features

Server-side execution · ease of use · open source · cross-platform · database integration (MySQL, SQLite) · built-in functions · interoperability (HTML, JavaScript) · security features.

MySQL: 8 key features

Relational structure · SQL language · open source · cross-platform · high performance · scalability · security · integration (PHP, Python, Java).

Why PHP + MySQL work well together

ReasonMeaning
Dynamic contentPHP handles the logic, MySQL stores the data.
Easy integrationmysqli (MySQL only) and PDO (many databases).
Cost-effectiveBoth free and open source.
ScalabilityFrom small sites to large apps.
SecurityPrepared statements (stop SQL injection), authentication, role-based access.

PHP files and the 3 things you need

  • PHP files contain text, HTML and scripts, are returned as plain HTML, and use the .php extension.

  • You need a web server (Apache), a database server (MySQL) and a PHP parser.

How the stack works (memorize the order)

  1. Client request: browser asks for http://localhost/app.php.

  2. Web server: Apache sees .php and sends it to the PHP parser.

  3. PHP executes: runs the logic, may query MySQL.

  4. Response: the HTML goes back to the browser.

With a database: Browser → Apache → PHP → MySQL → PHP → Apache → Browser

XAMPP and Workbench

  • Start Apache and MySQL in the Control Panel; files go in htdocs; open http://localhost/folder/file.php (htdocs is not in the URL).

  • Add C:\xampp\php\ to Path so the terminal and VS Code find PHP.

  • Workbench connection: localhost, port 3306, user root (empty password on XAMPP).

Traps

  • Double-clicking a .php file opens file://, so PHP doesn't run.

  • View Page Source shows only HTML, never PHP.

  • phpMyAdmin = browser; Workbench = desktop.

  • mysqli = MySQL only; PDO = many databases.

  • 3306 = MySQL; 80 = Apache (HTTP); 443 = HTTPS.

  1. What does PHP stand for? 2. The 3 things needed? 3. Where do files go, and what URL? 4. Which tool designs ER diagrams? 5. What stops SQL injection?

Answers: 1) Hypertext Preprocessor. 2) Web server, database server, PHP parser. 3) htdocs; http://localhost/... 4) MySQL Workbench. 5) Prepared statements.

Lesson 2 — Basic Concepts (PHP Tutorial Part 2 + Week 2)

Big idea: PHP code lives inside <?php ... ?> tags in a .php file, stores data in $variables, and prints with echo.

Syntax

  • Standard tag: <?php ... ?> (preferred). Short tag <? ... ?> only works if the server enables it.

  • Every statement ends with ;.

  • A PHP block can go anywhere in the HTML.

  • index.php is the default file a server opens for a folder (like main in Java/C++).

Comments

StyleUse
// textOne line
# textOne line
/* text */Several lines

Variables: the naming rules

  • Start with $, then a letter or underscore (never a number).

  • Only letters, numbers and _ (no spaces, no dashes): $my_string or $myString.

  • Case-sensitive: $age and $AGE are different variables.

  • PHP is loosely typed: the type comes from the value, and a variable can change type ($value = 10; then $value = "Hello";).

Data types

String · Integer · Float · Boolean · Array · Object · NULL (a variable with no value is NULL).

Automatic type conversion (type juggling)

$x = 10;
$y = "20";
echo "x + y is: ", $x + $y;   // x + y is: 30

+ is always math, so "20" becomes 20. . is always joining text: "5" . "3" is "53", "5" + "3" is 8.

Constants

define("PI", 3.14);
echo PI;        // 3.14
const x = 10;
echo x;         // 10

No $, the value can't change, and constants are global (available everywhere).

Variable functions

FunctionReturns / does
isset($v)true if it exists and is not NULL; false if never set, set to NULL, or unset
unset($v)Destroys the variable
empty($v)true for "", 0, 0.0, "0", NULL, false, array(), undefined
gettype($v)The type as text: gettype("4 months") is string; floats show as double
var_dump($v)Type and value: var_dump(5985) is int(5985)

Concatenation

$txt1 = "Hello World!";
$txt2 = "What a nice day!";
echo $txt1 . " " . $txt2;   // Hello World! What a nice day!

Case sensitivity

  • NOT case-sensitive: keywords (echo, if, while), function names, classes. ECHO, echo and EcHo all work. This is why a function named MIN clashes with min().

  • Case-sensitive: variable names. $color vs $COLOR gives "Undefined variable $COLOR".

echo vs print

echoprint
ArgumentsOne or more (echo "a", "b";)Only one
Return valueNoneReturns 1 ($r = print "Hi"; makes $r 1)

Double vs single quotes

$name = "Josh";
echo "Hello $name";   // Hello Josh
echo 'Hello $name';   // Hello $name
$x = 5; $y = 4;
echo $x + $y;         // 9
echo "$x + $y";       // 5 + 4

Double quotes put in the variable's value; single quotes print the text exactly as written.

Traps

  • A file saved as .html doesn't run PHP.

  • $2nd, $my name and $price-tag are invalid names.

  • empty(" ") is false (a space is a character); trim first.

  • "$x + $y" prints the text, not the sum.

  • Missing ; causes a parse error.

Lesson 3 — Data Types and Type Casting (PHP Tutorial Part 3)

Big idea: every value has a type. PHP converts types automatically (implicit) when it needs to, and you can convert them yourself (explicit) with (int), (float), (string), (bool).

The data types

String · Integer · Float · Boolean · Array · Object · NULL

Numeric strings, INF and NaN

Strings

  • Double quotes put in variables ("Hello $x"); single quotes don't ('Hello $x').

  • Joining: $x . $y is HelloWorld; $x . " " . $y or "$x $y" adds the space.

  • Boolean: true / false, used in conditions.

  • NULL: the only value of type NULL. A variable with no value is NULL; $x = null; empties it.

Implicit casting (automatic, done by PHP)

echo $a + $b;    // 30    the string becomes a number

var_dump(2 / 4); // float(0.5)

  • (int) cuts, it doesn't round: use round() to round.

  • A leading 0 makes a number octal: 017 is 15.

  • "0" and "" are false; "false" is true.

  • strpos() counts from 0.

  • Comparing floats with == can fail.

  1. var_dump(4 * 2.5); prints? 2. (int) 9.99 is? 3. (bool) "0" is? 4. echo 10 . 20; prints? 5. strpos("PHP rocks", "rocks") returns?

Answers: 1) float(10). 2) 9. 3) false. 4) 1020. 5) 4.

Lesson 4 — Control Statements and Loops (PHP Tutorial Part 4)

Big idea: conditions choose which code runs (if, switch), loops repeat code (while, do...while, for, foreach), and operators do the math and comparisons inside them.

Conditional statements

StatementUse it when
ifRun code only if a condition is true
if...elseOne block if true, another if false
if...elseif...elsePick one of several blocks
switchPick one of many blocks by comparing one value to several cases
$score = 85;
if ($score >= 90) {
    echo "Grade: A";
} elseif ($score >= 80) {
    echo "Grade: B";      // this one runs
} elseif ($score >= 70) {
    echo "Grade: C";
} else {
    echo "Grade: F";
}

  • The first true condition wins; the rest are skipped, which is why the order goes from highest to lowest.

  • More than one line after if or else needs { }.

switch

$x = 2;
switch ($x) {
    case 1: echo "Number 1"; break;
    case 2: echo "Number 2"; break;   // Number 2
    case 3: echo "Number 3"; break;
    default: echo "No number between 1 and 3";
}

The value is checked once and compared to each case. break stops it; without break it falls through into the next case. default runs when nothing matches.

Loops

LoopChecks the conditionRuns at least once?Best for
whileBefore each roundNoRepeat while something is true
do...whileAfter each roundYesRun once, then repeat while true
forBefore each roundNoA known number of times (counter)
foreachOne round per itemNoEvery item in an array
$i = 1;
while ($i <= 5) {
    echo "The number is " . $i . "<br>";   // 1 to 5
    $i++;
}

for ($i = 1; $i <= 5; $i++) {
    echo "The number is " . $i . "<br>";   // 1 to 5
}

for (init; condition; increment): init runs once, the condition is checked before every round, the increment runs at the end of every round.

Trap from the handout's do...while: it does $i++ before echo, so starting at 1 it prints 2 3 4 5 6, not 1 to 5. And do { ... } while ($i < 5); with $i = 10 still prints 10 once.

break stops the loop completely; continue skips the rest of this round and goes to the next.

Conditional assignment: ternary cond ? a : b and ?? ($_POST["name"] ?? "").

Traps

  • echo (5 == 8); prints nothing: false prints as an empty string, true prints 1.

  • = assigns, == compares, === also checks the type.

  • Missing break in switch runs the next case too.

  • do...while always runs once.

  • % is the remainder: $n % 2 == 0 means even.

  1. $x = 7; echo $x % 3; prints? 2. Which loop always runs at least once? 3. echo (10 > 3); prints? 4. $s = "Hi"; $s .= "!"; makes $s? 5. A switch case with no break?

Answers: 1) 1. 2) do...while. 3) 1. 4) "Hi!". 5) It falls through into the next case.

Lesson 5 — Arrays (PHP Tutorial Part 5)

Big idea in one line

An array keeps many related values in one variable. PHP has three kinds: indexed, associative and multidimensional.

The three kinds

KindKeysExampleAccess
Indexed (numeric)0, 1, 2... (automatic)$fruits = ["Apple", "Banana", "Cherry"];$fruits[1] is Banana
AssociativeNames you choose$age = ["Joe" => 22, "Alex" => 25];$age["Joe"] is 22
MultidimensionalArrays inside an array$cars = [["Volvo", 22, 18], ["BMW", 15, 13]];$cars[1][0] is BMW

Creating arrays

$fruits = array("Apple", "Banana", "Cherry");   // array() function
$fruits = ["Apple", "Banana", "Cherry"];        // short syntax, same thing
$fruits[3] = "Mango";                           // set an index by hand
$fruits[] = "Kiwi";                             // add to the end
$age['Peter'] = 30;                             // add a key to an associative array
$schedule = [16 => 'My Birthday', 20 => 'Special Dinner'];   // keys can be integers
echo $schedule[20];                             // Special Dinner

  • => links a key to its value.

  • Indexes start at 0.

  • PHP arrays can grow and mix types (unlike C arrays).

Looping

$fruits = ['Apple', 'Banana', 'Orange', 'Mango'];
for ($x = 0; $x < count($fruits); $x++) {
    echo $fruits[$x] . "<br>";
}

foreach ($fruits as $value) {             // indexed: just the value
    echo $value . "<br>";
}

$people = ['Joe' => 22, 'Adam' => 25];
foreach ($people as $name => $age) {      // associative: key and value
    echo "My name is $name, and age is $age<br>";
}

Two-dimensional arrays (rows and columns)

[0] Name[1] Stock[2] Sold
[0]Volvo2218
[1]BMW1513
[2]Saab52
[3]Land Rover1715
echo $cars[1][0] . ": In stock: " . $cars[1][1] . ", sold: " . $cars[1][2] . ".";
// BMW: In stock: 15, sold: 13.

for ($row = 0; $row < 4; $row++) {         // outer loop = rows
    for ($col = 0; $col < 3; $col++) {     // inner loop = columns
        echo $cars[$row][$col] . " ";
    }
}

  • A 2D array needs two indices: first the row, then the column. A 3D array needs three.

  • Going through every item needs two nested loops.

Useful array functions

FunctionExampleResult
count()count(["a", "b", "c"])3

print_r()print_r($fruits)shows the whole array

Traps to avoid

  • Indexes start at 0: the 3rd item is [2].

  • echo $array; doesn't print the items; use print_r(), var_dump() or a loop.

  • Associative keys are case-sensitive strings: $age["joe"] is not $age["Joe"].

  • count() of a 2D array counts rows only.

  • Reading a key that doesn't exist gives a warning; check with isset() first.

Answers: 1) Blue. 2) =>. 3) 2. 4) Two. 5) foreach ($arr as $key => $value).

Lesson 6 — Functions (PHP Tutorial Part 6)

Big idea in one line

A function is a named block of code you write once and call whenever you need it. It doesn't run until it's called.

Built-in vs user-defined

  • Built-in: PHP has thousands ready to use (echo, define(), var_dump(), strlen(), count()).

  • User-defined: functions you write yourself.

Writing a function

function writeName($fname) {             // $fname is a parameter
    echo $fname . " Refsnes.<br>";
}
writeName("Kai Jim");                     // Kai Jim Refsnes.
writeName("Hege");                        // Hege Refsnes.

function add($x, $y) {
    $total = $x + $y;
    return $total;                         // hands the answer back
}
echo "1 + 16 = " . add(1, 16);            // 1 + 16 = 17
PartMeaning
functionStarts the definition
NameStarts with a letter or underscore; describes what it does
ParametersVariables in ( ) that receive the values you pass
returnSends a value back to where it was called (and ends the function)
Calladd(1, 16): the values passed are the arguments

Default argument values

function setHeight($minheight = 50) {
    echo "The height is : $minheight <br>";
}
setHeight(350);   // The height is : 350
setHeight();      // The height is : 50  (default used)

Type declarations and strict types

function addNumbers(int $a, int $b) {
    return $a + $b;
}
echo addNumbers(5, "5");   // 10  ("5" is converted)

  • With declare(strict_types=1); on the very first line, the types must match exactly: addNumbers(5, "5") throws a TypeError.

  • Handout correction: it says addNumbers(5, "5 days") returns 10 without strict mode. In PHP 8 it's a TypeError either way; only a clean numeric string like "5" converts. (Tested in PHP 8.3.)

Variable scope

ScopeWhere it's visibleHow to use it inside a function
LocalOnly inside the function where it's createdNormal
GlobalOutside functionsglobal $x; or $GLOBALS['x']
StaticInside the function, but keeps its value between callsstatic $x = 0;
$x = 5; $y = 10;
function myTest() {
    global $x, $y;
    $y = $x + $y;
}
myTest();
echo $y;          // 15

function counter() {
    static $x = 0;
    echo $x;
    $x++;
}
counter(); counter(); counter();   // 012

Traps to avoid

  • Defining a function doesn't run it; you must call it.

  • A function can't see outside variables unless you use global, $GLOBALS, or pass them as arguments.

  • Function names are not case-sensitive, so you can't name one MIN, max or count (they already exist): Fatal error: Cannot redeclare.

  • Code after return in the same block never runs.

  • Without static, a local variable starts over every call (000 instead of 012).

  2. What keyword lets a function use an outside variable?

  3. What does static do?

  4. Why does function MIN($a, $b) fail?

  5. Where must declare(strict_types=1); go?

Answers: 1) 6. 2) global (or $GLOBALS). 3) Keeps the variable's value between calls. 4) PHP already has min(), and function names ignore case. 5) The very first line of the file.

Lesson 7 — Form Handling (PHP Tutorial Part 7)

Big idea in one line

An HTML form collects input, the browser sends it (GET or POST), and PHP reads it from a superglobal like $_POST or $_GET.

Static page vs web application

  • Static: HTML only; the content doesn't change by itself.

  • Web application: runs on a server (Apache) with server-side code (PHP, Node.js, Python) for logic, data and databases. The browser is the HTTP client.

The form

<form action="process.php" method="post">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">
  <input type="submit" value="Submit">
</form>

  • action: the PHP file that receives the data (action="" = the same page).

  • method: get or post.

  • name="...": becomes the key in $_POST / $_GET. A box with no name isn't sent.

Workflow: HTML form → submit (GET/POST) → PHP reads it with $_POST / $_GET / $_REQUEST → validate, process, maybe save to a database.

Superglobals (always available, in any scope)

$GLOBALS · $_SERVER · $_REQUEST · $_POST · $_GET · $_FILES · $_ENV · $_COOKIE · $_SESSION

SuperglobalHolds
$GLOBALSAll global variables: $GLOBALS['z'] = $GLOBALS['x'] + $GLOBALS['y'];
$_SERVERServer and request info: PHP_SELF (this file), SERVER_NAME, REQUEST_METHOD
$_POSTData sent with POST
$_GETData sent with GET or in the URL query string
$_REQUESTGET + POST + COOKIE together

The same-file pattern (the page runs twice)

<form method="POST" action="<?php echo htmlspecialchars($_SERVER['PHP_SELF']); ?>">
  Name: <input type="text" name="fname">
  <input type="submit">
</form>
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $name = $_POST['fname'];
    if (empty($name)) {
        echo "Name is empty";
    } else {
        echo $name;
    }
}
?>

  1. First load (GET): the if is false, so you just see the form.

  2. After Submit (POST): the same file runs again, the if is true, and PHP checks the name.

Query strings and GET

<a href="demo_phpfile.php?subject=PHP&web=W3schools.com">Test $GET</a>
echo "Study " . $_GET['subject'] . " at " . $_GET['web'];   // Study PHP at W3schools.com

? starts the query string, & separates the key=value pairs. A GET form sends welcome_get.php?name=John&email=john@example.com.

GET vs POST

GETPOST
Where the data goesIn the URLInside the request body
Visible?Yes (address bar, history)No
Size limitAbout 2000 charactersNo practical limit (8 MB default, post_max_size)
Bookmark / shareYesNo
Use forSearches, links, filtersLogins, passwords, forms that save or change data

Rule: GET asks to see something; POST sends something to be processed.

Redirects

header("Location: welcome.php");
exit;   // always exit after a redirect

header() must run before any output (echo or HTML), or you get "headers already sent".

Case study: the login

Login.php (form with action="login_process.php" method="POST") → login_process.php reads $_POST['username'] and $_POST['password'], compares them to John / 123, and prints a green or red message.

Traps to avoid

  • The name in the form must match the key in PHP exactly (fname vs name = undefined key; the handout's $_REQUEST example has this typo).

  • Form method GET but PHP reads $_POST = nothing.

  • Never send passwords with GET.

  • Printing PHP_SELF without htmlspecialchars() is an XSS risk.

  • header() after output fails; forgetting exit lets the script keep running.

Quick self-check (answers below)

  1. Which attribute says where the form data goes?

  2. Name 3 superglobals.

  3. page.php?city=Queens: how do you read Queens?

  4. Which method for a login form?

  5. What must come right after header("Location: ...")?

Answers: 1) action. 2) e.g. $_POST, $_GET, $_SERVER. 3) $_GET['city']. 4) POST. 5) exit;

The form pattern

  1. Start every value and error variable empty: $nameErr = $name = "";

  2. Check only after submit: if ($_SERVER["REQUEST_METHOD"] == "POST") (or isset($_POST['submit'])).

  3. Required check first, then the format check.

  4. Print each error next to its box: <span class="error">* <?php echo $nameErr; ?></span>

  5. Keep what the user typed: value="<?php echo $name; ?>"; radios use checked.

Traps to avoid

  • empty("0") is true, empty(" ") is false: trim() first.

  • is_numeric() accepts decimals and negatives; use ctype_digit() for zip codes.

  • An empty name passes the pattern (* allows zero characters), so check required first.

  • filter_var() returns the value or false, so use ! to catch a bad one.

  • Printing input without htmlspecialchars() leaves an XSS hole.

Lesson 9 — Sessions and Cookies (PHP Tutorial Part 9)

Big idea in one line

HTTP forgets you after every page (stateless). A session remembers you on the server; a cookie remembers you on your computer.

Sessions

  1. The user connects; the server starts a session.

  2. The server stores the data and sends a session ID to the browser, usually as a cookie (PHPSESSID).

  3. Every later request includes the session ID.

  4. The server checks the ID and responds.

  5. The session ends: logout, browser closed, or timeout.

<?php
session_start();                        // FIRST, before any HTML, on every page
$_SESSION["favcolor"] = "green";        // save
echo $_SESSION["favcolor"];             // read
$_SESSION["favcolor"] = "yellow";       // change
unset($_SESSION["favcolor"]);           // remove one value
session_unset();                        // remove all values
session_destroy();                      // destroy the session
?>

  • Session variables hold info about one user and are available on all pages; by default they last until the browser closes.

  • If cookies are off, the ID can go in the URL (risk: session hijacking).

Cookies

A small text file the browser stores, sent back to the site with every request, to remember data across visits.

<?php
setcookie("user", "John Doe", time() + (86400 * 30), "/");   // 30 days, whole site
?>
<html><body>
<?php
if (!isset($_COOKIE["user"])) {
    echo "Cookie named 'user' is not set!";
} else {
    echo "Value is: " . $_COOKIE["user"];
}
?>
</body></html>

4 ways to pass data between pages

Session · Cookie · POST/GET form · URL query string (welcome.php?id=110&name=John read with $_GET['id']; visible, so never for passwords).

Traps to avoid

  • session_start() and setcookie() before any output.

  • Forgot session_start() on a page = empty $_SESSION.

  • A new cookie isn't in $_COOKIE until the next load.

  • Delete a cookie with the same path you created it with.

  • Never store passwords in cookies or URLs.
