Lesson 1 — Introduction (PHP Tutorial Part 1)

Big idea: PHP runs on the server, talks to MySQL for data, and sends only HTML to the browser.

Key terms

TermWhat to remember

PHP: 8 key features

Server-side execution · ease of use · open source · cross-platform · database integration (MySQL, SQLite) · built-in functions · interoperability (HTML, JavaScript) · security features.

MySQL: 8 key features

Relational structure · SQL language · open source · cross-platform · high performance · scalability · security · integration (PHP, Python, Java).

PHP files and the 3 things you need

  • PHP files contain text, HTML and scripts, are returned as plain HTML, and use the .php extension.

  • You need a web server (Apache), a database server (MySQL) and a PHP parser.

How the stack works (memorize the order)

  1. Client request: browser asks for http://localhost/app.php.

  2. Web server: Apache sees .php and sends it to the PHP parser.

  3. PHP executes: runs the logic, may query MySQL.

  4. Response: the HTML goes back to the browser.

With a database: Browser → Apache → PHP → MySQL → PHP → Apache → Browser

XAMPP and Workbench

  • Start Apache and MySQL in the Control Panel; files go in htdocs; open http://localhost/folder/file.php (htdocs is not in the URL).

  • Add C:\xampp\php\ to Path so the terminal and VS Code find PHP.

  • Workbench connection: localhost, port 3306, user root (empty password on XAMPP).

Traps

  • Double-clicking a .php file opens file://, so PHP doesn't run.

  • View Page Source shows only HTML, never PHP.

  • phpMyAdmin = browser; Workbench = desktop.

  • mysqli = MySQL only; PDO = many databases.

  • 3306 = MySQL; 80 = Apache (HTTP); 443 = HTTPS.

Answers: 1) Hypertext Preprocessor. 2) Web server, database server, PHP parser. 3) htdocs; http://localhost/... 4) MySQL Workbench. 5) Prepared statements.

Lesson 2 — Basic Concepts (PHP Tutorial Part 2 + Week 2)

Big idea: PHP code lives inside <?php ... ?> tags in a .php file, stores data in $variables, and prints with echo.

Syntax

  • Standard tag: <?php ... ?> (preferred). Short tag <? ... ?> only works if the server enables it.

  • Every statement ends with ;.

  • A PHP block can go anywhere in the HTML.

  • index.php is the default file a server opens for a folder (like main in Java/C++).

Comments

StyleUse
// textOne line
# textOne line
/* text */Several lines

Variables: the naming rules

  • Start with $, then a letter or underscore (never a number).

  • Only letters, numbers and _ (no spaces, no dashes): $my_string or $myString.

  • Case-sensitive: $age and $AGE are different variables.

  • PHP is loosely typed: the type comes from the value, and a variable can change type ($value = 10; then $value = "Hello";).

Data types

String · Integer · Float · Boolean · Array · Object · NULL (a variable with no value is NULL).

Automatic type conversion (type juggling)

$x = 10;
$y = "20";
echo "x + y is: ", $x + $y;   // x + y is: 30

+ is always math, so "20" becomes 20. . is always joining text: "5" . "3" is "53", "5" + "3" is 8.

Constants

define("PI", 3.14);
echo PI;        // 3.14
const x = 10;
echo x;         // 10

No $, the value can't change, and constants are global (available everywhere).

Variable functions

FunctionReturns / does
isset($v)true if it exists and is not NULL; false if never set, set to NULL, or unset
unset($v)Destroys the variable
empty($v)true for "", 0, 0.0, "0", NULL, false, array(), undefined
gettype($v)The type as text: gettype("4 months") is string; floats show as double

Concatenation

$txt1 = "Hello World!";
$txt2 = "What a nice day!";
echo $txt1 . " " . $txt2;   // Hello World! What a nice day!

Case sensitivity

  • NOT case-sensitive: keywords (echo, if, while), function names, classes. ECHO, echo and EcHo all work. This is why a function named MIN clashes with min().

  • Case-sensitive: variable names. $color vs $COLOR gives "Undefined variable $COLOR".

echo vs print

echoprint
ArgumentsOne or more (echo "a", "b";)Only one
Return valueNoneReturns 1 ($r = print "Hi"; makes $r 1)
SpeedSlightly fasterSlightly slower

Double vs single quotes

$name = "Josh";
echo "Hello $name";   // Hello Josh
echo 'Hello $name';   // Hello $name
$x = 5; $y = 4;
echo $x + $y;         // 9
echo "$x + $y";       // 5 + 4

Double quotes put in the variable's value; single quotes print the text exactly as written.

Traps

  • A file saved as .html doesn't run PHP.

  • $2nd, $my name and $price-tag are invalid names.

  • empty(" ") is false (a space is a character); trim first.

  • "$x + $y" prints the text, not the sum.

  • Missing ; causes a parse error.
