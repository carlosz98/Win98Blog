Week 7, Day 1 — Tuesday 11/03/2026: No class, Assignment 2 (Sessions)

There was no class today. The work for this day is Assignment 2 (100 points): four PHP pages that share data with sessions (Lesson 9).

What the assignment asks

  1. Home page: links to all the other pages. It works as the index.

  2. Login page: two text boxes (username and password) and one Submit button.

    • If the user enters username = Mike and password = 12345, save both into sessions and send the user to the welcome page.

    • Anything else prints: "username and password incorrect".

  3. Welcome page: test if the sessions are set. If they are, print their values (username and password). If not, print "sessions are not set". It needs a link back to the home page.

  4. Log out page: called from the Log out link on the home page. It removes all sessions (the remove code goes in this page) and sends the user back to the home page. After that, the welcome page must print "sessions are not set".

index.php (Home page)

<?php
session_start();
?>
<!DOCTYPE html>
<html>
<head>
    <title>Home Page</title>
</head>
<body>
<h1>Home Page</h1>
<a href="login.php">Login</a><br>
<a href="welcome.php">Welcome</a><br>
<a href="logout.php">Log out</a>
</body>
</html>

login.php (Login page)

<?php
session_start();

$message = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $username = $_POST["username"];
    $password = $_POST["password"];

    if ($username == "Mike" && $password == "12345") {
        $_SESSION["username"] = $username;
        $_SESSION["password"] = $password;
        header("Location: welcome.php");
        exit;
    } else {
        $message = "username and password incorrect";
    }
}
?>
<!DOCTYPE html>
<html>
<head>
    <title>Login Page</title>
</head>
<body>
<h1>Login</h1>
<form method="POST" action="<?php echo htmlspecialchars($_SERVER['PHP_SELF']); ?>">
    Username: <input type="text" name="username"><br><br>
    Password: <input type="password" name="password"><br><br>
    <input type="submit" value="Submit">
</form>
<?php echo $message; ?>
</body>
</html>

welcome.php (Welcome page)

<?php
session_start();
?>
<!DOCTYPE html>
<html>
<head>
    <title>Welcome Page</title>
</head>
<body>
<h1>Welcome Page</h1>
<?php
if (isset($_SESSION["username"]) && isset($_SESSION["password"])) {
    echo "Username: " . $_SESSION["username"] . "<br>";
    echo "Password: " . $_SESSION["password"] . "<br>";
} else {
    echo "sessions are not set<br>";
}
?>
<br>
<a href="index.php">Home</a>
</body>
</html>

logout.php (Log out page)

<?php
session_start();
session_unset();
session_destroy();
header("Location: index.php");
exit;
?>

How it works

  • session_start() is the first line on every page, before any HTML, so each page can read or change $_SESSION.

  • login.php uses the same-file pattern: the first load just shows the form; after Submit, $_SERVER["REQUEST_METHOD"] == "POST" is true and PHP checks the values.

  • With Mike / 12345, it saves both values into $_SESSION first, then redirects with header("Location: welcome.php"); exit;.

  • welcome.php uses isset() on both session values to decide which message to print.

  • logout.php has no HTML: session_unset() removes the values, session_destroy() ends the session, then it redirects home.

How to run it in XAMPP

  1. Put the four files in a folder inside htdocs (for example htdocs/assignment2/).

  2. Start Apache in the XAMPP Control Panel.

  3. Open localhost/assignment2/index.php and follow the six steps above, taking a screenshot of each.

Things to remember

  • header() must run before any output, or you get "headers already sent". Always put exit; after it.

  • "mike" is not "Mike": the == comparison of strings is case-sensitive.

  • Forgetting session_start() on the welcome page makes it always say "sessions are not set", even after a correct login.

  • Saving a password in a session is only for this assignment; real sites never store or print the password.
