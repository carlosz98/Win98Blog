Notes on the requirements

  • Skills (D): the languages and tools used in this course — PHP, MySQL, JavaScript, and Node.js — all fit this section, alongside HTML and CSS.

  • ERD (E): an Entity-Relationship Diagram shows the database's entities (the things being stored, such as Customer or Book), each entity's attributes (its fields, such as name or price), and the relationships between entities (such as a Customer places many Orders). It is the plan for the MySQL tables.

  • Key tasks (C): the instructions ask for bullet points, so keep each task short and action-based.
