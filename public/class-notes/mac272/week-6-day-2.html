1. What does the var_dump() function do in PHP?

  • a) Outputs text and variables

  • b) Outputs formatted text

  • c) Returns the data type and value of a variable

  • d) Converts variables to lowercase

Answer: c. var_dump() shows the type and the value (and the length for strings).

string(2) means a string with 2 characters. (Strictly, var_dump() prints this information; it does not return it. The choice still describes it best.)

2. What is the correct way to access the value 'Mango' in this multidimensional array?

$fruits = array(
   array('Apple', 'Banana'),
   array('Orange', 'Mango') );

  • a) $fruits[1][1]

  • b) $fruits[2][2]

  • c) $fruits['Orange']['Mango']

  • d) $fruits['Mango'][1]

Answer: a. The first bracket picks the row (the inner array), the second picks the item in that row, and both start at 0.

[0][1]
$fruits[0]AppleBanana
$fruits[1]OrangeMango
echo $fruits[1][1];   // Mango

  • b) is wrong because index 2 does not exist (each array only has 0 and 1).

  • c) and d) are wrong because this is an indexed array: the keys are numbers, not the values.

3. What is the role of the $_POST superglobal in PHP form handling?

  • a) Retrieve information sent with the GET method

  • b) Collect values from a form sent with method="post"

  • c) Display form data in the browser's address bar

  • d) Set form action URL for form submission

Answer: b. a) is $_GET. c) is what GET does, not POST. d) is the form's action attribute.

4. What is the purpose of the isset() function in PHP form handling?

  • a) To check if a variable is set and not NULL

  • b) To set cookies for form data

  • c) To display form data in a tabular format

  • d) To redirect the user to another page

Answer: a. b) is setcookie(). d) is header("Location: ..."). c) is not something isset() does.

5. Which PHP function removes unnecessary characters like extra spaces and tabs from user input?

  • a) strip_tags()

  • b) trim()

  • c) clean_input()

  • d) validate_input()

Answer: b. trim() removes spaces, tabs and new lines from both ends. strip_tags() removes HTML tags. clean_input() and validate_input() are not built-in PHP functions (you would have to write them, like test_input()).

6. Which PHP function is used to check if a string contains only letters and whitespace?

  • a) check_string()

  • b) validate_string()

  • c) test_input()

  • d) preg_match()

Answer: d. With a pattern: preg_match("/^[a-zA-Z ]*$/", $name). a) and b) do not exist, and test_input() is the handout's own cleaning function (trim and stripslashes), not a check.

Q3: Code question

Write a PHP code snippet to cast a float variable $x = 10.75 to an integer and store it in a variable $Y. Print the value of $Y.

<?php
$x = 10.75;
$Y = (int) $x;
echo $Y;
?>

Output:

10

  • (int) cuts off the decimals. It does not round, so 10.75 becomes 10, not 11. (To round, use round($x), which gives 11.)

  • Variable names are case-sensitive: $Y and $y are different variables. Use exactly $Y as the question says.

  • (integer) and intval($x) also work.

The sheet's login page (with one typo fixed: the submit button had a stray => after name="submit"):

 </form>

The sheet asks for process_login.php that:

  1. a) Reads the username and password submitted from the login page. [1 pt]

  2. Creates any type of array(s) that store usernames and their passwords for two users. [1 pt]

The sheet only prints 2 of the 5 points. The rest is most likely the same as Assignment 1 (loop through the arrays, go to a welcome page when found, show an error when not), so the full script covers those too:

<?php
// a) Read the username and password submitted from the login page
$username = $_POST["username"] ?? "";
$password = $_POST["password"] ?? "";

// 2) Arrays that store the usernames and passwords of two users
$usernames = ["carlos", "maria"];
$passwords = ["carlos1", "abc456"];

// Loop through the arrays to look for a match
$found = false;
for ($i = 0; $i < count($usernames); $i++) {
    if ($username === $usernames[$i] && $password === $passwords[$i]) {
        $found = true;
        break;
    }
}

if ($found) {
    header("Location: welcome.php");
    exit;
} else {
    echo "username and password incorrect";
}
?>

Output:

You typeResult
carlos / carlos1Redirect to welcome.php
maria / abc456Redirect to welcome.php
carlos / xusername and password incorrect

Three ways to build the arrays for two users (any one gets the point):

// Option 1: two parallel arrays (same position = same user)
$usernames = ["carlos", "maria"];
$passwords = ["carlos1", "abc456"];

// Option 2: one associative array (username => password)
$users = ["carlos" => "carlos1", "maria" => "abc456"];

// Option 3: a multidimensional array (one row per user)
$users = [
    ["carlos", "carlos1"],
    ["maria",  "abc456"]
];

How to check each one:

// Option 2
if (isset($users[$username]) && $users[$username] === $password) { /* found */ }

// Option 3
foreach ($users as $user) {
    if ($username === $user[0] && $password === $user[1]) { /* found */ }
}

In Option 3, $user[0] is the username and $user[1] is the password, the same row/item idea as the Mango question.

Q2 [2 pts]: The MIN function

Write a PHP script that defines a function named MIN that takes two numbers as parameters and returns the smaller value. Call the function and print the result.

Watch out: PHP already has a built-in function min(), and PHP function names are not case-sensitive, so MIN and min are the same name. Running function MIN($a, $b) gives:

PHP Fatal error: Cannot redeclare MIN()

I tested this in PHP 8.3. On paper the answer is graded on the logic, but when you run it, use another name such as findMin (or myMin).

The version that runs:

<?php
function findMin($a, $b) {
    if ($a < $b) {
        return $a;
    } else {
        return $b;
    }
}

$result = findMin(8, 3);
echo "The smaller value is: " . $result;
?>

Output:

The smaller value is: 3

  • function findMin($a, $b) defines the function with two parameters.

  • if ($a < $b) return $a; else return $b; hands back the smaller one. A one-line version uses the ternary operator: return ($a < $b) ? $a : $b;

  • findMin(8, 3) calls it, and echo prints the result.

  • PHP's own min(8, 3) also returns 3, which is exactly why the name MIN is already taken.

Q7: Check a form's name and age

A form with a name box and an age box submits to the same page. Task 1: show a message if the name is empty. Task 2: show a message if the age is not a number.

<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {

    // Task 1: is the name field empty?
    if (empty($_POST["name"])) {
        echo "Name is required";
    }

    // Task 2: is the age a number?
    if (!is_numeric($_POST["age"])) {
        echo "Age must be a number";
    }
}
?>

  • REQUEST_METHOD == "POST" runs the checks only after the form is submitted.

  • empty() catches a blank name.

  • is_numeric() checks the age, and the ! flips it, so the message shows when the age is not a number.

  • The form has no action, so it submits back to the same page, and the PHP can sit in the same file as the form.

  • "name" and "age" must match the name attributes of the inputs.
