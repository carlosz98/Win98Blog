CSS concepts used in the project

1. Three ways to add CSS

Your project uses an external stylesheet on every page: <link rel="stylesheet" href="oatmeal.css">. The other two ways are internal (a <style> block in the <head>) and inline (<p style="color:red">). External is best because one file can style many pages.

2. Rule anatomy

h3 {
  font-size: 1.5rem;
  color: #555;
  margin: 15px 0 10px;
}

h3 is the selector, each property: value; line is a declaration, and the whole thing is a rule. Every declaration ends with a semicolon. Comments look like /* Page Container */.

4. The CSS reset and box-sizing

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
  font-family: Arial, sans-serif;
}

Browsers give elements default margins and padding; this reset removes them so every browser starts equal. box-sizing: border-box makes width include padding and border, so a 300px box stays 300px after you add padding. Arial, sans-serif is a font stack: if Arial is missing, any sans-serif font is used.

Side effect you can see in the screenshot: the reset also removes the left padding of <ul>, so the bullets in "Recipe Ingredients" hang outside the box.

5. The box model

Every element is a box made of 4 layers, inside to outside: content, padding, border, margin.

.container {
  max-width: 800px;
  margin: 0 auto;      /* 0 top/bottom, auto left/right = centered */
  padding: 20px;
  border-radius: 10px;
  box-shadow: 0 2px 5px rgba(0, 0, 0, 0.2);
  overflow: hidden;
}

  • Shorthand order is clockwise from the top: margin: 15px 0 10px = top 15, left/right 0, bottom 10.

  • margin: 0 auto centers a block that has a width or max-width.

  • max-width: 800px lets the card shrink on small screens but never grow past 800px.

  • border-radius rounds corners; box-shadow: x y blur color adds a shadow.

  • overflow: hidden clips anything that sticks out of the box.

6. Colors and units

  • Hex: #333 is short for #333333 (dark gray); #007BFF is the blue button.

  • rgba: rgba(0, 0, 0, 0.2) is black at 20% opacity, used for soft shadows.

  • px is a fixed size. rem is relative to the root font size (usually 16px), so 2rem = 32px. % is relative to the parent: width: 10% on the logo means 10% of its container's width.

  • line-height: 1.6 (no unit) means 1.6 times the font size.

7. Text properties

text-align (center, left, justify), text-transform: uppercase (why "Oatmeal Recipes" shows as OATMEAL RECIPES), text-decoration: none (removes link underlines), font-weight: bold, font-size.

8. display: block, inline, inline-block

  • block takes the full width and starts on a new line (<div>, <p>, <h2>, <section>).

  • inline sits inside a line of text and ignores width/height (<a>, <span>).

  • inline-block sits in the line but accepts width, height, padding and margin.

You used inline-block twice: on h2 so its bottom border is only as wide as the text, and on a so "Back to Home" becomes a padded button.

9. Responsive images

img {
  max-width: 100%;
  height: auto;
}

The image can never be wider than its container, and height: auto keeps its proportions. This is the standard way to stop big photos from breaking a layout on phones.

10. Flexbox (the nav bar)

nav ul {
  display: flex;
  list-style: none;
  justify-content: center;
}

display: flex lays the <li> items out in a row instead of a vertical list. justify-content: center centers them on the main (horizontal) axis. list-style: none removes the bullets. Other values to know: flex-start, flex-end, space-between, space-around; align-items controls the cross (vertical) axis; flex-direction: column stacks items.

11. CSS Grid (the home page content)

main {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 20px;
}

fr means a fraction of the free space: the middle column is twice as wide as each side column. The 5 sections fill the grid in order, left to right, then wrap to a new row. gap is the space between cells. Flexbox is one-dimensional (a row or a column); Grid is two-dimensional (rows and columns).

12. Transitions and hover

nav ul li a {
  transition: background-color 0.3s ease;
}
nav ul li a:hover {
  background-color: #ddd;
}

The :hover rule changes the color; transition makes the change fade over 0.3 seconds instead of jumping.

13. The cascade, inheritance and specificity

  • Cascade: when two rules set the same property with equal weight, the later one wins.

  • Specificity decides first: inline style > #id > .class / :hover > element. So .recipe-description img { width: 100% } beats img { ... }.

  • Inheritance: text properties like color, font-family and line-height set on body pass down to children. Box properties like margin and border do not.
