How this project works

The Recipes site is 6 plain HTML pages, each with its own CSS file, linked together from one home page. There is no JavaScript: everything is markup (HTML) plus styling (CSS), and every image comes from the images/ folder.

What happens when someone opens the site:

  1. The browser loads index.html and reads the <head>. The <link rel="stylesheet" href="styles.css"> line tells it to download and apply styles.css.

  2. It draws the <body> top to bottom: <header> with the h1, the logo section, the <nav> list (turned into a horizontal bar by display: flex), the <main> grid, then the <footer>.

  3. Clicking a nav link like <a href="oatmeal.html"> loads a new page. Because the path has no folder in it, the browser looks for the file next to index.html.

  4. The recipe page loads its own CSS, which centers a white .container card on a light gray page.

  5. "Back to Home" is another <a href="index.html">, styled as a blue button.

All paths are relative (images/avocado.jpg, oatmeal.html), so the site works from any folder or web host as long as the files keep the same layout. The 4 recipe stylesheets are identical to each other; only the HTML content differs.
