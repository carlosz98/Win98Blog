Likely test points

HTML

  • The parts of the skeleton: <!DOCTYPE html>, <html lang>, <head>, <body>, and what each <meta> line does.

  • Where the <title> text appears (browser tab), and that it is not shown on the page.

  • Semantic tags (header, nav, main, section, footer) vs div, and why semantics help accessibility and SEO.

  • <ul> vs <ol>, and that <li> must be inside one of them.

  • Relative vs absolute paths; what images/avocado.jpg means.

  • Void elements (<img>, <br>, <meta>, <link>) have no closing tag.

  • Purpose of alt text; required attributes of <img> (src, alt) and <a> (href).

  • HTML entities like &copy;, &amp;, &lt;.

  • class (reusable) vs id (unique).

CSS

  • External vs internal vs inline CSS, and which wins when they conflict (inline).

  • Selector, declaration, property, value, rule; semicolons and braces.

  • Selector types: universal, element, class, id, descendant, grouping, pseudo-class.

  • Box model order (content, padding, border, margin) and box-sizing: border-box.

  • Shorthand order: margin: 15px 0 10px and margin: 0 auto.

  • Units: px, rem, %, fr.

  • block vs inline vs inline-block.

  • Flexbox (display: flex, justify-content, align-items) vs Grid (grid-template-columns, gap).

  • :hover and transition.

  • Cascade, specificity and inheritance.

  • Spotting a broken rule (like the p rule in styles.css) and fixing it.

Quick self-quiz (answers below)

  1. In grid-template-columns: 1fr 2fr 1fr, how wide is the middle column compared to each side column?

  2. Why does every h2 on the recipe pages appear in capital letters even though the HTML says "Oatmeal Recipes"?

  3. What does margin: 0 auto do to .container?

  4. Why does the p { font-size: 30px font bold; } rule have no effect?

  5. What CSS turns the nav <ul> into a horizontal bar, and what removes its bullets?

  6. Which wins for an image in .recipe-description: img { ... } or .recipe-description img { ... }? Why?

  7. What is the difference between <a href="index.html"> and <a href="https://example.com/index.html">?

  8. Why is a set to display: inline-block on the recipe pages?

Answers: 1) Twice as wide. 2) text-transform: uppercase. 3) Removes top/bottom margin and centers it horizontally. 4) A missing semicolon makes the value invalid, so the browser drops the whole declaration. 5) display: flex and list-style: none. 6) The class selector, because it has higher specificity. 7) The first is relative to the current folder; the second is an absolute URL. 8) So padding and margin apply and the link looks like a button.
