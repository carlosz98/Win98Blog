Systemd

Systemd is the first process the kernel starts (PID 1); it starts everything else and you control it with systemctl.

Key concepts

  • Every OS component systemd manages is a unit. Daemons are service units (sshd.service); old-style runlevels are target units (targets).

  • systemctl starts, stops and restarts daemons and sets them to start at boot. systemd-analyze shows info about units and boot time.

  • The default target is a symbolic link: /etc/systemd/system/default.target.

Targets

TargetPurpose
poweroff.targetshut down
rescue.targetemergency / troubleshooting
multi-user.targetcommand line (CLI)
graphical.targetGUI (default when a GUI is installed)
reboot.targetreboot

Commands

systemctl restart crond.service       # restart a daemon
systemctl get-default                 # show default target
systemctl set-default multi-user.target   # boot to CLI
systemctl set-default graphical.target    # boot to GUI
systemctl isolate rescue.target       # switch target now
systemd-analyze                       # boot time info
