Chapter 3: Exploring Linux Filesystems

Linux stores everything in one tree that starts at /; you move through it with paths, list it with ls, read files with cat/less, search them with grep and edit them with vi.

Key concepts

  • Root directory is /, the top of the tree. (The slide says "/root", but /root is the root user's home folder. Know the difference.)

  • Absolute path starts at / (/etc/passwd). Relative path starts from where you are (docs/notes.txt).

  • ~ = your home directory, .. = parent directory, . = current directory. Tab completes names.

  • File types: text, binary data, linked, special device, named pipe, socket.

  • Filenames: up to 255 characters; most Linux files have no extension. Names starting with . are hidden.

  • ls -l columns: type, permissions, hard link count, owner, group owner, size, modification time, name.

  • Wildcards (interpreted by the shell, match filenames) vs regular expressions (interpreted by a text tool, match text inside files).

  • grep = common regexp, egrep (grep -E) = extended regexp, fgrep (grep -F) = no regexp, fastest.

  • vi / vim is bi-modal: command mode (delete, copy, save, quit) and insert mode (typing text). Esc goes back to command mode; settings go at the : prompt.

  • Other editors: Emacs, nano (Ctrl key shortcuts), gedit (GUI).

Wildcards

WildcardMatches
*0 or more characters
?exactly 1 character
[aegh]1 character that is a, e, g or h
[a-e]1 character from a to e
[!a-e]1 character NOT from a to e

Commands

pwd                 # print working directory
cd /etc             # absolute path
cd ..               # up one level
cd ~                # go home
ls -F               # add / * @ to show file type
ls -l               # long listing
ls -a               # include hidden files
file /bin/ls        # what type of file is it
cat -n file         # show file with line numbers
tac file            # show file in reverse (newest log lines first)
head -5 file        # first lines (default 10)
tail -5 file        # last lines (default 10)
less file           # page through, arrow keys work
strings /bin/ls     # text inside a binary
od -x file          # dump file in hex (od alone = octal)
grep -i error /var/log/messages   # case-insensitive search
grep -v '^#' file   # lines that do NOT start with #
