Chapter 7: Working with the BASH Shell

BASH lets you redirect and pipe command input and output, store values in variables, and chain commands into scripts with if, for and while.

Key concepts

  • File descriptors: 0 = stdin (input), 1 = stdout (normal output), 2 = stderr (errors).

  • > overwrites a file, >> appends, < feeds a file in as stdin. 2> redirects errors only.

  • Pipe | sends one command's stdout into the next command's stdin. Filter commands read stdin and write stdout (sort, grep, sed, awk, tr...). Input redirection goes at the start of a pipe, output redirection at the end.

  • tee writes to a file and to the screen. sed finds and replaces or deletes lines. awk treats each line as a record and each word as a field ($1, $2...). tr swaps characters.

  • Variable types: environment (system ones like PATH, HOME), user-defined, special.

  • PATH lists the folders searched for commands, so you can type ls instead of /usr/bin/ls. Don't change HOME or PWD.

  • Variable names: letters, numbers, underscore; can't start with a number; usually CAPITALS.

  • A subshell doesn't see your variables unless you export them. set lists all variables, env lists exported ones.

  • Variables vanish when the shell exits; put them in environment files: /etc/profile, /etc/bashrc (everyone), ~/.bashrc, ~/.bash_profile, ~/.bash_login, ~/.profile (one user).

  • Shell script = text file of commands. First line is the shebang / hashpling: #!/bin/bash. Run it with bash script.sh (needs read) or ./script.sh (needs read and execute).

  • echo -e enables escape sequences: \n new line, \t tab, \a beep, \c no newline, \\ backslash.

  • if ... then ... elif ... else ... fi (fi = if backwards). Test operators: -o OR, -a AND, ! NOT.

  • cmd1 && cmd2 runs cmd2 only if cmd1 succeeded; cmd1 || cmd2 runs cmd2 only if cmd1 failed.

  • for loops over a list; while repeats as long as a test is true (usually with a counter).

Commands

ls /etc /fake > out.txt 2> err.txt   # stdout and stderr to separate files
ls /etc /fake > all.txt 2>&1         # both into one file
date >> log.txt                      # append
tr a-z A-Z < file.txt > upper.txt    # stdin in, stdout out (different names!)
ls -l /etc | grep conf | less        # pipes
cat file | sort | tee sorted.txt     # save and show
sed 's/cat/dog/g' file.txt           # replace every cat with dog
sed '/^#/d' file.txt                 # delete comment lines
awk '{print $1, $3}' file.txt        # print fields 1 and 3
echo $PATH ; echo $HOME              # read variables
MYVAR="hello" ; export MYVAR         # create and export
set ; env ; history                  # list variables, exported vars, past commands
alias ll='ls -l'                     # shortcut
read NAME                            # put user input into NAME

Script example

#!/bin/bash
echo -e "What is your name? \c"
read NAME
if [ "$NAME" = "Carlos" ]
then
    echo "Welcome back"
elif [ -z "$NAME" ]
then
    echo "You typed nothing"
else
    echo "Hello $NAME"
fi

for FILE in /etc/hosts /etc/passwd
do
    echo "Found $FILE"
done

COUNTER=1
while [ $COUNTER -le 3 ]
do
    echo "Count $COUNTER"
    COUNTER=$((COUNTER + 1))
done

mkdir /tmp/test && echo "made it" || echo "failed"
