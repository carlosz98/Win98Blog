Chapter 9: Managing Linux Processes

A process is a program running in memory; you view processes with ps, pstree and top, stop them with kill signals, and change their priority with nice and renice.

Key concepts

  • Program = executable file on disk. Process = that program running in memory and on the CPU.

  • User process runs from a terminal; daemon is a system process with no terminal.

  • PID = process ID. PPID = parent's PID. A parent starts child processes.

  • systemd (PID 1) starts most daemons; login starts BASH, and BASH starts your commands. Every process traces back to systemd through PPIDs.

  • Process states: R running, S sleeping, Z zombie (finished, but the parent hasn't released its PID; also called defunct). Kill the parent to clear a zombie.

  • Nice value (NI): from -20 (most likely high priority) to 19 (lowest priority). Default 0. Only root can lower a nice value.

  • SZ = size of the process in memory (KB).

  • Berkeley-style options have no dash: a (all terminals), x (no terminal).

  • Rogue process = faulty process eating resources; find it in top and kill it.

  • Killing a parent also kills its children.

  • killall kills by name; pkill kills by name or regexp and other criteria.

Common kill signals (the signal table was an image in the slides; these are the standard ones from the textbook)

NumberNameMeaning
1SIGHUPHang up; many daemons reload their config
2SIGINTInterrupt, same as Ctrl+C
3SIGQUITQuit, same as Ctrl+\
9SIGKILLAbsolute kill; can't be caught or ignored
15SIGTERMPolite terminate; the default for kill
18SIGCONTContinue a stopped process
19SIGSTOPStop (pause), like Ctrl+Z

Commands

ps                  # your processes in this terminal
ps -ef              # every process, full info (UID, PID, PPID, start time)
ps -el              # long format: shows state (S), nice (NI), size (SZ)
ps ax               # Berkeley style: all processes
pstree              # family tree of processes
top                 # live view, highest CPU first (k = kill, r = renice, q = quit)
kill 3674           # send SIGTERM (15) to PID 3674
kill -9 3674        # force kill
kill -l             # list all signals
killall -9 firefox  # kill every process named firefox
pkill -u bob sleep  # kill bob's sleep processes
nice -n 10 ./big.sh # start with lower priority
renice +5 3674      # change priority of a running process
renice +5 -u bob    # root: change all of bob's processes
sleep 100 &         # run in the background
jobs ; fg %1 ; bg %1  # list jobs, bring to front, resume in back

Scheduling (in the chapter objectives, not in these slides)

at 10:30pm          # run commands once at a time (Ctrl+D to finish)
atq ; atrm 3        # list / remove at jobs
crontab -e          # edit your repeating jobs
crontab -l          # list them
# cron line: minute hour day-of-month month day-of-week command
30 2 * * 1 /root/backup.sh   # every Monday at 2:30 AM
