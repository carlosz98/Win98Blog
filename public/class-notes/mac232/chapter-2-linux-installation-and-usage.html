Chapter 2: Linux Installation and Usage

Installing Linux means checking hardware, picking install media, partitioning the disk and creating accounts; using it means talking to the kernel through a shell on a terminal.

Key concepts

  • HCL (Hardware Compatibility List): check every hardware part against it on the vendor site before installing.

  • Fedora 28 minimums: 1 GHz x64 CPU, 1 GB RAM, 10 GB disk.

  • ISO image: a downloadable DVD image. A live media image runs the whole OS from RAM so you can test drivers before installing. No DVD drive? Write the image to a USB stick (Fedora Media Writer).

  • Virtualization: a VM is an OS running inside virtualization software (Hyper-V, VMware, VirtualBox); the VM host is the OS underneath.

  • Install stages: start installer, choose language and localization, configure partitions and filesystems, configure user accounts.

  • Disk types: PATA, SATA, NVMe, SCSI, SAS.

  • Partitions: an MBR disk holds at most 4 primary partitions; one can be an extended partition split into logical drives. The MBR stores the partition table.

  • Linux needs only two partitions: one mounted at / (root) and one for swap (disk space used as overflow RAM).

  • Filesystems: ext2, ext3, ext4, VFAT, XFS. Journaling tracks what is written so the filesystem recovers faster after a crash.

  • LVM (Logical Volume Manager) and BTRFS are alternatives to standard partitions; standard, unencrypted partitions make recovery easier.

  • Accounts: root has full rights; also create a regular user.

  • Terminal = the channel you log in through. Shell = the program that takes your input and passes it to the kernel. BASH is the default shell.

  • Prompt: # means root, $ means regular user. Switch terminals with Ctrl+Alt+F2 (F1 to F6). Fedora's default GUI is GNOME.

  • Command anatomy: command (case sensitive), options (start with -), arguments (no dash).

  • Metacharacters have special meaning ($ = variable). Single quotes ' ' stop the shell from interpreting them.

  • Help: man pages (searchable by keyword) and info pages. Shell built-ins often have neither.

Commands

man ls            # manual page for ls
man -k password   # search man pages by keyword (same as apropos)
info ls           # GNU info page
shutdown -P +4    # power off in 4 minutes
shutdown -H +4    # halt in 4 minutes (no power off)
shutdown -r now   # reboot now
shutdown -c       # cancel a scheduled shutdown
halt / poweroff / reboot

Likely test points

  • Max 4 primary partitions on MBR; the two partitions Linux needs (/ and swap).

  • # vs $ prompt; Ctrl+Alt+F2 to change terminal.

  • Man section 1 vs 8; man -k searches.

  • shutdown -P, -H, -r, -c and what each does.

  • Don't just cut power: data in RAM may not be written to disk yet.
