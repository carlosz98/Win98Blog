Installing a Fedora VM (lab)

The lab installs Fedora from an ISO into a VirtualBox VM with 2 GB RAM and a 20 GB disk.

  1. Download the Fedora ISO from getfedora.org (the slide uses "Fedora 34 Standard ISO image for x86_64").

  2. Install VirtualBox from virtualbox.org with default options.

  3. In VirtualBox click New, name the VM, and click Next.

  4. Give it 2048 MB RAM.

  5. Create the disk with defaults but at least 20 GB (8 GB is too small).

  6. Open Settings > Storage, select the empty IDE controller, click the CD icon and pick the ISO.

  7. In Settings > System, set boot order to Hard Disk, then Optical.

  8. Start the VM, choose Start Fedora Live, then Install to Hard Drive.

  9. In the Installation Summary: Installation Destination > ATA VBOX HARDDISK > Done.

  10. Set the Root Password.

  11. User Creation: full name and username linux, set a password, tick Make this user an administrator.

  12. Click Begin Installation, then Reboot System and log in as root.

Passwords don't show any characters or dots while you type; just type and press Enter.

Likely test points: RAM and disk sizes, attaching the ISO under Storage, boot order, and making the user an administrator.
