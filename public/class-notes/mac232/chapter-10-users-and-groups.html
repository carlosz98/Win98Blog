Chapter 10: Users and Groups

User accounts live in /etc/passwd, passwords and expiry in /etc/shadow, and groups in /etc/group; you manage them with useradd, usermod, userdel, passwd, chage and the group commands.

Key concepts

  • Authentication = checking the username and password against the account database.

  • /etc/passwd: account info. Its password field just shows x.

  • /etc/shadow: the encrypted password plus expiry fields. pwconv turns shadow on; pwunconv goes back to passwd only.

  • UID = unique user ID; GID = the user's primary group ID. The primary group owns every file the user creates.

  • GECOS = text description (full name); often blank.

  • Order in /etc/passwd: root first, then daemon accounts, then regular users.

  • Lastchange = days since January 1, 1970 that the password was last changed.

  • Expiry fields in /etc/shadow: min (days before you may change it), max (days you may keep it), warn (days of warning before it expires), disable (days you can still log in after it expires).

  • /etc/group lists groups and members; a user can be in many groups.

  • New user defaults come from /etc/login.defs (mail location, password expiry, min length, UID/GID ranges) and /etc/default/useradd (primary group, home location, shell, skeleton directory).

  • Skeleton directory /etc/skel: environment files copied into every new home directory.

  • An account needs a password before it can log in. Root can change anyone's password.

  • Lock an account: usermod -L, passwd -l, or chsh to an invalid shell.

  • After userdel, the user's files show the old UID number as owner; the next user given that UID owns them.

Fields of an /etc/passwd line

carlos:x:1000:1000:Carlos Z:/home/carlos:/bin/bash

FieldExample
Usernamecarlos
Passwordx (real one is in /etc/shadow)
UID1000
GID1000
GECOSCarlos Z
Home directory/home/carlos
Shell/bin/bash

Commands

useradd -m -s /bin/bash -c "Bob Smith" bob   # create user with home, shell, comment
passwd bob                 # set bob's password (no argument = your own)
usermod -aG wheel bob      # add bob to the wheel group
usermod -L bob ; passwd -l bob   # lock the account
usermod -U bob ; passwd -u bob   # unlock it
chage -M 90 -W 7 bob       # max 90 days, warn 7 days before
chage -l bob               # show expiry info
chsh -s /sbin/nologin bob  # give an invalid shell
chfn bob                   # change GECOS info
userdel -r bob             # delete user and home directory
groupadd sales             # create group
groupmod -n market sales   # rename group
groupdel market            # delete group
groups bob ; id bob        # list bob's groups / UID and GIDs
newgrp sales               # temporarily switch primary group
