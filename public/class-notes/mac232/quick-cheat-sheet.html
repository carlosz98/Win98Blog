Easily mixed up

  • / (root directory) vs /root (root user's home).

  • Wildcards (shell, filenames) vs regular expressions (text tools, file contents).

  • Hard link (same inode, same filesystem) vs symbolic link (path pointer, can cross filesystems).

  • locate (database) vs find (live search) vs which (PATH).

  • df (filesystem free space) vs du (directory size).

  • nice (new process) vs renice (running process).

  • systemctl start (now) vs enable (at boot).

  • > overwrite vs >> append; && on success vs || on failure.

  • rpm (single package, no dependency help) vs dnf (repositories, resolves dependencies); .rpm vs .deb.

  • apt-get update (refresh package lists) vs apt-get upgrade (install newer versions).
