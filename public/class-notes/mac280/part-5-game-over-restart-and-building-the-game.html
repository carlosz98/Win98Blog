Part 5: Game over, restart and building the game

Part 5 ends the game when the bird hits a pipe, shows a Game Over screen with a Restart button, and exports a playable build.

Building the Game Over screen

  1. On the Canvas, add an empty child GameObject named GameOverScreen.

  2. Under it, add a Text that says "Game Over".

  3. Under it, add a Button, resize it, and change its child text to "Restart".

  4. Uncheck GameOverScreen in the Inspector so it starts hidden.

Restart and GameOver in LogicScript

using UnityEngine.SceneManagement;

public GameObject gameOverScreen;

public void restartGame()
{
    SceneManager.LoadScene(SceneManager.GetActiveScene().name);
}

public void gameOver()
{
    gameOverScreen.SetActive(true);
}

  • SceneManager.LoadScene() loads a scene by name or build index. Passing GetActiveScene().name reloads the current scene, which restarts the game and resets the score.

  • SetActive(true) turns a disabled GameObject back on, so the hidden screen appears.

  • Drag the GameOverScreen object into the gameOverScreen slot in the Inspector.

  • Both functions must be public so the button and other scripts can call them.

Hooking up the button

  1. Select the Button and find the On Click () list on its Button component.

  2. Click + to add an event, drag the Logic Manager object into the slot.

  3. From the dropdown pick LogicScript > restartGame.

BirdScript changes

public LogicScript logic;
public bool birdIsAlive = true;

void Start()
{
    logic = GameObject.FindGameObjectWithTag("Logic").GetComponent<LogicScript>();
}

void Update()
{
    if (Input.GetKeyDown(KeyCode.Space) && birdIsAlive)
    {
        myRigidbody.velocity = Vector2.up * flapStrength;
    }
}

private void OnCollisionEnter2D(Collision2D collision)
{
    logic.gameOver();
    birdIsAlive = false;
}

  • OnCollisionEnter2D runs when the bird's collider hits a solid collider (a pipe).

  • birdIsAlive stops the player from flapping after a crash; the && means both conditions must be true.

  • The slides spell these names both ways (GameOver / gameOver, RestartGame / restartGame). C# is case-sensitive, so the call must match the definition exactly.

Building the game

File > Build Settings (called Build Profiles in Unity 6) > Add Open Scenes > Build, then choose a folder for the output.
