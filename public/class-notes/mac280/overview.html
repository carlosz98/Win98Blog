MAC 280 - GAME PROGRAMMING

How this guide works

Across the five parts you build a Flappy Bird style game in Unity: a bird that flaps, pipes that spawn and scroll, a score, and a game over screen with restart. Each part below lists the key ideas, the editor steps and code from the slides, and the points most likely to show up on a test.

PartWhat you buildMain skills
1Your project setupUnity panels, importing assets (5 ways)
2The birdEmpty GameObject, Sprite Renderer, Circle Collider 2D, Rigidbody 2D, first C# script, keyboard input
3The pipesMoving with Time.deltaTime, prefabs, a spawner with a timer, random heights, destroying off-screen objects
4The scoreUI Canvas and Text, LogicScript, trigger colliders, tags and layers
5Game over and buildGame Over screen, Restart button, SceneManager, collisions, birdIsAlive, Build Settings
