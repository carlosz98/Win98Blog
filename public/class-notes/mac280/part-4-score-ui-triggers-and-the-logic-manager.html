Part 4: Score UI, triggers and the Logic Manager

Part 4 adds a score on screen that goes up by 1 each time the bird flies through the gap between pipes.

Setting up the UI

  1. GameObject > UI > Text (may be under Legacy). This creates a Canvas with the Text inside. UI elements are GameObjects too.

  2. Zoom far out in the Scene view to find the Canvas.

  3. Select the Canvas, find Canvas Scaler, set UI Scale Mode to Scale with Screen Size and pick a Reference Resolution (for example 1080p). This keeps the UI the same on every screen size.

  4. UI elements use a Rect Transform, not a normal Transform. Change Width and Height (for example 300 by 300), never Scale, to avoid stretching.

  5. Raise the Font Size, set the text to "0" and check it in the Game view.

  6. Create an empty GameObject named Logic Manager, tag it Logic, and add a script called LogicScript. It holds game-wide info like the score.

LogicScript

using UnityEngine;
using UnityEngine.UI;

public class LogicScript : MonoBehaviour
{
    public int playerScore;
    public Text scoreText;

    [ContextMenu("Increase Score")]
    public void addScore(int scoreToAdd)
    {
        playerScore = playerScore + scoreToAdd;
        scoreText.text = playerScore.ToString();
    }
}

  • using UnityEngine.UI is required to use the Text type.

  • scoreText is filled by dragging the Text object into the slot in the Inspector.

  • ToString() converts the int to a string, because a Text shows strings.

  • [ContextMenu("Increase Score")] lets you right-click the component in the Inspector and run the function to test it without playing. (It only works on methods with no parameters, so for testing use a small wrapper with no arguments, or give scoreToAdd a default value.)

Colliders vs triggers

ColliderTrigger (Is Trigger checked)
Blocks objectsYes, physical collisionNo, objects pass through
Used here forBird hitting a pipeDetecting the bird in the gap
Event functionOnCollisionEnter2D(Collision2D)OnTriggerEnter2D(Collider2D)

Steps: open the pipe prefab, add a child GameObject named Middle in the gap, add a Box Collider 2D, and check Is Trigger.

PipeMiddleScript

public class PipeMiddleScript : MonoBehaviour
{
    public LogicScript logic;

    void Start()
    {
        logic = GameObject.FindGameObjectWithTag("Logic").GetComponent<LogicScript>();
    }

    private void OnTriggerEnter2D(Collider2D collision)
    {
        if (collision.gameObject.layer == 3)
        {
            logic.addScore(1);
        }
    }
}

  • Pipes are spawned at runtime, so you cannot drag the Logic Manager into a prefab's slot. Instead the script finds it by tag in Start(): FindGameObjectWithTag("Logic") then GetComponent<LogicScript>().

  • Layer check: put the bird on layer 3 so only the bird scores, not other objects.

  • addScore can take other values (for example 5 for a bonus).
