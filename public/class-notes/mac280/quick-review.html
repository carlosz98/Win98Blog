Quick review

Glossary

TermMeaning
GameObjectAny object in a scene; a container for components
ComponentA piece of behavior added to a GameObject (Sprite Renderer, Rigidbody 2D, scripts)
PrefabA saved, reusable blueprint of a GameObject; edits apply to all copies
MonoBehaviourBase class that lets a C# script attach to a GameObject and get Start() and Update()
Start()Runs once when the object starts
Update()Runs every frame
Time.deltaTimeSeconds since the last frame; makes motion and timers frame-rate independent
InstantiateCreates a copy of a prefab at a position and rotation
DestroyRemoves a GameObject from the scene
Random.RangeRandom number between a minimum and maximum
TriggerA collider with Is Trigger checked; detects but does not block
TagA label used to find objects in code ("Logic")
LayerA numbered group used to filter what interacts (bird on layer 3)
CanvasThe root that holds all UI elements
Rect TransformThe Transform used by UI; size with Width and Height
SceneManagerLoads and reloads scenes (UnityEngine.SceneManagement)
SetActiveTurns a GameObject on or off
