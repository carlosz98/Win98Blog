Final review checklist

Tick these off before the exam; each one is a likely question.

  • Explain each line of Hello World and the difference between local and global scope

  • Write an overloaded function and a function with a default parameter

  • Compare a reference and a pointer, and say what & and * mean in each position

  • Declare a named struct, an array of structs, and pass a struct by pointer (->) and by reference (.)

  • Write a class with methods defined both inside and outside (ClassName::method)

  • Write a default and a parameterized constructor, including an initializer list

  • Fill in the public / protected / private access table from memory

  • Define encapsulation and write a private attribute with a getter and setter

  • Name and sketch the five inheritance types, and give the access-control rules for public, protected and private inheritance

  • Contrast compile-time and runtime polymorphism, and break down Number operator+(const Number& other)

  • Predict the output of the Animal/Dog/Cat pointer example (virtual vs non-virtual)

  • Write try/throw/catch with multiple catch blocks in the right order (specific first)

  • Match the four standard exceptions to when they're thrown, and write a custom exception that overrides what()

  • Create a thread, pass arguments five ways, and explain join vs detach and the danger of detaching with a local reference

  • Write to, append to, and read line by line from a file, checking is_open() and calling close()
