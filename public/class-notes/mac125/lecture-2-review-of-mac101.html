Lecture 2: Review of MAC101

This lecture reviews the basics everything else builds on: program structure, data types, control flow, arrays, functions and scope.

Key concepts

  • #include <iostream> gives you cin and cout. using namespace std; lets you write cout instead of std::cout.

  • int main() is where every program starts. << is the stream insertion operator.

  • Arrays store many values of one type: int nums[5];. Indexes run 0 to size - 1.

  • A function only runs when called. Parameters act as variables inside it. return sends a value back.

  • Default parameters are used when the caller leaves an argument out.

  • Function overloading: same name, different parameter list (number or types).

  • Scope: a local variable lives only inside its function or block; a global variable (declared outside every function) is visible everywhere.

#include <iostream>
using namespace std;

int total = 0;                       // global scope

void greet(string name = "Student") { // default parameter
    cout << "Hello " << name << "\n";
}

int add(int a, int b)       { return a + b; }  // overloading:
double add(double a, double b) { return a + b; }  // same name, different types

int main() {
    int scores[3] = {90, 85, 77};
    for (int i = 0; i < 3; i++) total += scores[i];
    greet();            // Hello Student
    greet("Carlos");    // Hello Carlos
    cout << add(2, 3) << " " << add(2.5, 1.5) << "\n";
    return 0;
}

Common mistakes

  • Reading scores[3] on a 3-element array (last valid index is 2).

  • Overloading only by return type; that does not compile, the parameters must differ.

  • Putting a default parameter before a non-default one (void f(int a = 1, int b) is an error).
