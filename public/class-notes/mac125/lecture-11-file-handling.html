Lecture 11: File Handling

Include <fstream> and use ofstream to write, ifstream to read and fstream for both; always check the file opened, then close it when done.

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

bool fileExists(const string& filename) {
    ifstream file(filename);
    return file.good();
}

int main() {
    // 1. Write
    ofstream outFile("MAC280.txt");
    if (outFile.is_open()) {
        outFile << "Hello, MAC280 Students!" << endl;
        outFile.close();
    } else {
        cerr << "Unable to open file for writing." << endl;
    }

    // 2. Append
    ofstream app("MAC280.txt", ios::app);
    if (app.is_open()) { app << "Final exam is on Monday." << endl; app.close(); }

    // 3. Read line by line
    ifstream inFile("MAC280.txt");
    if (inFile.is_open()) {
        string line;
        while (getline(inFile, line)) cout << line << endl;
        inFile.close();
    } else {
        cerr << "Unable to open file for reading." << endl;
    }

    cout << (fileExists("MAC280.txt") ? "File exists." : "File does not exist.") << endl;
    return 0;
}

  • is_open() checks the stream opened. Failures come from a missing file (reading) or permission/disk problems.

  • getline(inFile, line) reads a whole line, spaces included; inFile >> word stops at spaces, like cin.

  • cerr is the standard error stream, used for error messages.

  • close() frees the file and makes sure writes are saved.

Common mistakes

  • Opening with plain ofstream when you meant to add data: it wipes the file. Use ios::app.

  • Skipping the is_open() check and reading from a stream that failed.

  • Using >> to read sentences and getting only the first word.

  • Writing while (!inFile.eof()), which can process the last line twice. Loop on getline instead.
