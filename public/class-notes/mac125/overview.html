MAC 125 - ADVANCED C/C++ PROGRAMMING

Study notes for MAC125 Advanced C++ (Prof. Khalid Kassou), built from Lectures 1 to 11. Each lecture section has the key ideas, a short code example in the style of the slides, common mistakes, and what is likely to be on the test.

Grading: Laboratory 25%, Project 20%, Midterm 25%, Final 30%. The two exams are 55% of the grade, so the "Likely test points" lists are the parts to drill.

The course builds in one line: plain C++ review, then references and pointers, then structs, then classes (constructors, access, encapsulation), then the OOP big three (inheritance, polymorphism), and finally exceptions, threads and files.
