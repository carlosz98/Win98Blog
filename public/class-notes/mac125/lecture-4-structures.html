Lecture 4: Structures

A struct groups related variables (members) of different types under one name; unlike an array, the members can be int, string, bool and so on.

Key concepts

  • Anonymous struct: struct { int myNum; string myString; } myStructure; creates one variable directly.

  • One struct, several variables: struct { ... } myCar1, myCar2;

  • Named struct acts as a new data type you can reuse: struct Car { ... }; then Car c1;

  • Access members with the dot operator c1.brand. Through a pointer use the arrow: ptr->brand.

  • Arrays of structs: Book library[5] = { {"1984", "George Orwell", 1949}, ... };

  • Nested structs: a Department holds a Course courses[10] array plus a courseCount.

  • Structs can be passed to functions by value (a copy), by reference (&) or by pointer (*).

#include <iostream>
#include <string>
using namespace std;

struct BankAccount {
    int accountNumber;
    string ownerName;
    double balance;
};

void deposit(BankAccount* acc, double amount) {    // pointer: use ->
    if (amount > 0) acc->balance += amount;
}

void withdraw(BankAccount& acc, double amount) {   // reference: use .
    if (amount > 0 && amount <= acc.balance) acc.balance -= amount;
    else cout << "Invalid or insufficient funds.\n";
}

void display(const BankAccount& acc) {             // read-only reference
    cout << acc.ownerName << ": $" << acc.balance << "\n";
}

int main() {
    BankAccount a = {1001, "John Doe", 500.0};
    deposit(&a, 200.0);     // pass the address
    withdraw(a, 150.0);
    display(a);             // John Doe: $550
    return 0;
}

Common mistakes

  • Forgetting the semicolon after the closing brace: struct Car { ... };

  • Passing a struct by value and expecting the original to change. The slide's modifyPhone(Contact c, ...) works only because it returns the copy and you assign it back.

  • Using . on a pointer instead of -> (or (*ptr).member).

Likely test points: declare a named struct and an array of them, loop and print members, the BankAccount example (pointer vs reference parameter), struct vs class (members of a struct are public by default, a class's are private).
