~ What is it? ~

The classic word game in a C++ console. A random word is picked from a built-in list, and every wrong letter adds a body part to the ASCII gallows. Six misses and it's over!
  • Game class tracks the word, the revealed letters and the misses
  • Message class draws everything: the title screen, the gallows and the YOU WIN banner
  • Input is validated, so only new letters count
  • Made in January 2025
