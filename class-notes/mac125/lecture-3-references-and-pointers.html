Lecture 3: References and Pointers

A reference is a permanent second name for a variable; a pointer is a variable that holds another variable's memory address.

References

  • Declared with & between the type and the name: int& ref = x;

  • Must be initialized when declared, and cannot be re-bound to a different variable later.

  • Mostly used for function parameters: no copy is made, and the function can change the caller's variable.

Pointers

  • Declared with *: int* ptr;

  • &x (address-of) gives the address of x; *ptr (dereference / indirection) reads or changes the value at that address.

  • Used for dynamic memory and for working with variables and arrays directly.

#include <iostream>
using namespace std;

void swapRef(int& a, int& b) {   // pass by reference
    int t = a; a = b; b = t;
}

int main() {
    int x = 5, y = 9;
    int& r = x;        // r is another name for x
    r = 7;             // x is now 7

    int* p = &y;       // p holds y's address
    *p = 20;           // y is now 20
    cout << &x << "\n";  // prints x's memory address (e.g. 0x7ffd...)

    swapRef(x, y);     // x = 20, y = 7
    cout << x << " " << y << "\n";
    return 0;
}

Common mistakes

  • Mixing up the two meanings of &: in a declaration it makes a reference, in an expression it takes an address.

  • Mixing up the two meanings of *: in a declaration it makes a pointer, in an expression it dereferences.

  • Declaring int& r; with no initializer (compile error).

  • Dereferencing an uninitialized or null pointer (crash / undefined behavior).
