Lecture 7: Inheritance

Inheritance lets a derived (child) class reuse the attributes and methods of a base (parent) class, forming a hierarchy of shared logic.

The five types

TypeShapeExample
SingleOne base → one derivedDog : Animal
MultipleSeveral bases → one derivedFlyingCar : Car, Plane
MultilevelA chain: derived becomes a baseAnimal → Dog → Puppy
HierarchicalOne base → several derivedAnimal → Dog, Animal → Cat
HybridA mix of two or more of the aboveMultilevel + multiple together

Access control when inheriting

Inheritance modeBase public becomesBase protected becomesBase private
publicpublicprotectedNot accessible
protectedprotectedprotectedNot accessible
privateprivateprivateNot accessible
#include <iostream>
using namespace std;

class Animal {                         // base class
protected:
    string name;
public:
    Animal(string n) : name(n) {}
    void eat() { cout << name << " is eating\n"; }
};

class Dog : public Animal {            // single inheritance
public:
    Dog(string n) : Animal(n) {}       // call the base constructor
    void bark() { cout << name << " says woof\n"; }  // can use protected name
};

class Puppy : public Dog {             // multilevel: Animal -> Dog -> Puppy
public:
    Puppy(string n) : Dog(n) {}
    void weep() { cout << name << " is weeping\n"; }
};

class Swimmer { public: void swim() { cout << "Swimming\n"; } };
class Lab : public Dog, public Swimmer {   // multiple inheritance
public:
    Lab(string n) : Dog(n) {}
};

int main() {
    Puppy p("Rex");
    p.eat(); p.bark(); p.weep();       // gets all three levels
    Lab l("Max");
    l.bark(); l.swim();
    return 0;
}

Common mistakes

  • Leaving out public in class Dog : Animal. For a class the default is private inheritance, so eat() becomes private in Dog.

  • Trying to use a base class's private member in the derived class.

  • Not calling the base constructor when the base has no default constructor.

  • Mixing up multiple (many parents, one child) with hierarchical (one parent, many children).

Likely test points: name and sketch the five types, the access-control table, syntax class Derived : public Base, constructor order (base constructor runs first, then derived).
