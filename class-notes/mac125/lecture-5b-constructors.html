Lecture 5b: Constructors

A constructor is a special member function with the same name as the class and no return type (not even void); it runs automatically when an object is created and sets up its starting values.

Key concepts

  • Default constructor: takes no parameters (MyClass()).

  • Parameterized constructor: takes values to customize the new object (Car(string x, string y, int z)).

  • A class can have several constructors (constructor overloading), like Course() and Course(string, string, int).

  • Constructors can be declared inside the class and defined outside with Car::Car(...).

  • Member initializer list: : courseCode(c), title(t), credits(n) {} initializes members before the body runs.

#include <iostream>
using namespace std;

class Course {
public:
    string courseCode, title;
    int credits;

    Course() : courseCode(""), title(""), credits(0) {}            // default
    Course(string c, string t, int n)                              // parameterized
        : courseCode(c), title(t), credits(n) {}

    void display() const {
        cout << courseCode << ": " << title << " - " << credits << " Credits\n";
    }
};

class Car {
public:
    string brand; int year;
    Car(string b, int y);         // declaration
};
Car::Car(string b, int y) {       // definition outside the class
    brand = b; year = y;
}

int main() {
    Course c("MAC125", "Advanced C++", 4);
    c.display();                  // MAC125: Advanced C++ - 4 Credits
    Car car1("BMW", 1999);
    return 0;
}

The slide's CourseManager combines both ideas: its constructor CourseManager() : numCourses(0) {} starts the count at 0, and addCourse stores Course objects in a fixed array of 10.

Common mistakes

  • Giving a constructor a return type (void Car() is just a normal method, not a constructor).

  • Spelling the constructor name differently from the class.

  • Writing Course c(); to make an object with the default constructor. That declares a function; write Course c;

  • Defining only a parameterized constructor and then trying Course c; (no default constructor exists anymore).

Likely test points: the three facts on the definition slide (same name, no return type, called automatically), default vs parameterized, defining a constructor outside the class, initializer list syntax.
