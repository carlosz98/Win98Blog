Lecture 5a: Classes

A class is a user-defined type that bundles data (attributes) and functions (methods) into one blueprint; an object is one thing built from that blueprint.

Key concepts

  • OOP vs procedural: procedural code writes functions that act on data; OOP creates objects that hold both data and the functions that act on it.

  • OOP advantages from the slides: clear structure, keeps code DRY ("Don't Repeat Yourself"), easier to maintain/modify/debug, reusable with less code.

  • Real-life example: a car is an object; weight and color are attributes; drive and brake are methods. Attributes and methods together are "class members".

  • Create objects with ClassName obj; and access members with the dot syntax obj.member.

  • Methods can be defined inside the class, or outside using the scope resolution operator ::.

#include <iostream>
using namespace std;

class Car {
public:
    string brand;
    int year;

    void honk() {                 // defined inside the class
        cout << brand << " says beep!\n";
    }
    int age(int currentYear);     // declared only
};

int Car::age(int currentYear) {   // defined outside with ::
    return currentYear - year;
}

int main() {
    Car c1;                       // multiple objects from one class
    c1.brand = "BMW"; c1.year = 1999;
    Car c2;
    c2.brand = "Ford"; c2.year = 1969;
    c1.honk();
    cout << c2.age(2026) << "\n";   // 57
    return 0;
}

Common mistakes

  • Forgetting public:; class members are private by default, so c1.brand won't compile.

  • Writing int age(int y) { ... } outside the class without Car:: (that makes a separate free function).

  • Missing the ; after the class's closing brace.

Likely test points: class vs object, attribute vs method, defining a method outside the class with ::, the four OOP advantages.
