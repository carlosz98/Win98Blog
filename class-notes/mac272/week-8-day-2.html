Every file: connect, query, close

<?php
$conn = mysqli_connect("localhost", "root", "", "CollegeDB");
if (!$conn) {
    die("Connection failed: " . mysqli_connect_error());
}

$sql = "...";
if (mysqli_query($conn, $sql)) {
    echo "Done";
} else {
    echo "Error: " . mysqli_error($conn);
}

mysqli_close($conn);
?>

  • XAMPP's MySQL user is root with an empty password.

  • die() stops the page if the connection fails, so nothing else runs without a database.

  • To create the database itself, leave out the 4th argument, because it doesn't exist yet.

Reading rows

$result = mysqli_query($conn, "SELECT * FROM Students");
if (mysqli_num_rows($result) > 0) {
    while ($row = mysqli_fetch_assoc($result)) {
        echo $row["firstname"] . " " . $row["lastname"] . "<br>";
    }
} else {
    echo "0 results";
}

Why a while loop: mysqli_fetch_assoc() gives the next row each time and NULL after the last one, which ends the loop.

Functions

FunctionDoes
mysqli_connect()Opens the connection
mysqli_query()Runs SQL: a result for SELECT, true for others
mysqli_multi_query()Runs several statements joined with ;
mysqli_num_rows()How many rows came back
mysqli_fetch_assoc()Next row as an associative array
mysqli_insert_id()id of the last inserted row
mysqli_error()Last error message
mysqli_close()Closes the connection

Notes

  • In SQL, text uses single quotes ('John'); numbers and NULL don't.

  • Column options: NOT NULL (required), DEFAULT, UNSIGNED (no negatives), AUTO_INCREMENT (+1 each row), PRIMARY KEY (unique id).

  • Always use WHERE with UPDATE and DELETE, or every row changes.

  • Prepared statements (? and bind_param("sss", ...); types i/d/s/b) protect against SQL injection.

Seeing the data: phpMyAdmin

The PHP pages show the data in your own HTML table. To see what is really stored, open phpMyAdmin (the browser tool that comes with XAMPP):

  1. Start Apache and MySQL in the XAMPP Control Panel.

  2. Go to http://localhost/phpmyadmin.

  3. Click CollegeDB, then Students. Browse shows the rows (SELECT * FROM Students).

Useful tabs: Structure (the columns and their types), SQL (type and run a query), Insert, and Edit/Delete on each row. Refresh after each PHP file to see the change.

Output in phpMyAdmin after Part 3: CollegeDB → Students → Browse shows the 5 rows that insert_students.php added ("Showing rows 0 - 4 (5 total)", with ids 1–5 from AUTO_INCREMENT).
