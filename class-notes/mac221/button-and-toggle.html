Button and Toggle

A Button runs code when tapped; a Toggle flips a Bool on and off. Both usually work with @State, the property wrapper that stores a value inside a view and redraws the view when it changes.

@State and bindings

  • @State private var isOn = false stores view-owned data. Changing it redraws body.

  • $isOn (with the dollar sign) is a binding: a two-way link that lets a control both read and write the value. Controls like Toggle, TextField, Picker and DatePicker need a binding.

  • isOn.toggle() flips a Bool between true and false.

Button

Button(action: {
    print("Hello World tapped!")
}) {
    Text("Hello World")              // the label: any view
        .padding()
        .background(Color.purple)
        .foregroundColor(.white)
        .font(.title)
}

Button("Show details") { showDetails.toggle() }   // short form with a text title

Button {                                          // trailing-closure form
    print("Image tapped!")
} label: {
    Image("ocean").resizable().scaledToFit()
}

Show and hide with state:

struct ContentView: View {
    @State private var showDetails = false

    var body: some View {
        VStack(alignment: .leading) {
            Button("Show details") { showDetails.toggle() }
            if showDetails {                       // only drawn when true
                Text("You should enjoy SwiftUI").font(.largeTitle)
            }
        }
    }
}

The slides also use the ternary operator to style by state: .background(isTapped ? Color.blue : Color.gray). The flip-card example swaps between "Front of Card" and "Back of Card" with if isFlipped { ... } else { ... } and a button calling isFlipped.toggle().

Toggle

struct ContentView: View {
    @State private var isOn: Bool = false

    var body: some View {
        Toggle("Enable Feature", isOn: $isOn)     // note the $
            .padding()
    }
}

Custom label that changes with the value:

Toggle(isOn: $isOn) {
    HStack {
        Image(systemName: isOn ? "sun.max.fill" : "moon.fill")
            .foregroundColor(isOn ? .yellow : .gray)
        Text(isOn ? "Day Mode" : "Night Mode")
    }
}

A settings screen groups toggles in a Form with Section headers:

Form {
    Section(header: Text("Notifications")) {
        Toggle("Enable Notifications", isOn: $notificationsEnabled)
        Toggle("Enable Location Services", isOn: $locationEnabled)
    }
    Section(header: Text("Privacy")) {
        Toggle("Enable Dark Mode", isOn: $darkModeEnabled)
    }
    Section(header: Text("General")) {
        Toggle("Example General Setting", isOn: .constant(false))   // fixed value, can't change
    }
}
.navigationTitle("Settings")

To run code when a toggle changes, use .onChange(of: isOn) { newValue in ... }. (The "Toggle With Action" slide in the deck is blank, so this is the standard way, not copied from the slide.)
