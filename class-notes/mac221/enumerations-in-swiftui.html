Enumerations in SwiftUI

An enum is a user-defined type for a fixed group of related values. It makes code more readable, easier to maintain and type-safe, because the compiler only allows the listed cases.

The slides give three uses:

  1. View states: the different states a screen can be in.

  2. Picker options: a well-defined set of choices, like rainbow colors or product sizes.

  3. Modeling data types: user roles, product types, and so on, which prevents type mismatches.

Enum for view states, with switch

enum ViewState {
    case initial
    case appearing
    case disappearing
    case active
}

struct ContentView: View {
    @State private var viewState: ViewState = .initial   // short form: .initial

    var body: some View {
        VStack {
            Button("Change View State") {
                switch viewState {                       // cycle to the next state
                case .initial:      viewState = .appearing
                case .appearing:    viewState = .active
                case .active:       viewState = .disappearing
                case .disappearing: viewState = .initial
                }
            }

            switch viewState {                           // show different content per state
            case .initial:      Text("View State: Initial").foregroundColor(.gray)
            case .appearing:    Text("View State: Appearing").foregroundColor(.green)
            case .active:       Text("View State: Active").foregroundColor(.blue)
            case .disappearing: Text("View State: Disappearing").foregroundColor(.red)
            }
        }
    }
}

No default is needed because the switch covers every case. That is one of the main benefits of enums.

A two-state version uses the ternary operator: Button(viewState == .initial ? "Appear" : "Disappear") { viewState = viewState == .initial ? .active : .initial }.

Enum for a Picker

enum RainbowColor: String, CaseIterable, Identifiable {
    case red, orange, yellow, green, blue, indigo, violet
    var id: RainbowColor { self }
}

struct ContentView: View {
    @State private var selectedColor: RainbowColor = .red

    var body: some View {
        VStack {
            Picker("Rainbow Color", selection: $selectedColor) {
                ForEach(RainbowColor.allCases) { color in
                    Text(color.rawValue.capitalized).tag(color)
                }
            }
            .pickerStyle(SegmentedPickerStyle())
            Text("You selected: \(selectedColor.rawValue.capitalized)")
        }
    }
}
PieceWhy it's there
: StringGives each case a raw value, its name as text (.red.rawValue == "red")
CaseIterableAdds allCases, an array of every case, so ForEach can loop over them
Identifiable + var idLets ForEach tell the cases apart without id: \.self
.tag(color)Tag type matches the @State type (RainbowColor)
.capitalizedTurns "red" into "Red"
