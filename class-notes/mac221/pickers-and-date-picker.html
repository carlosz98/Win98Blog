Pickers and Date Picker

A Picker lets the user choose one value from a set. It needs a @State variable for the selection, passed with $, and each option needs a .tag() whose value has the same type as that variable.

Basic Picker

struct ContentView: View {
    @State private var option = 1                 // 1 = starts on MAC220

    var body: some View {
        VStack {
            Picker("Course Picker", selection: $option) {
                Text("MAC220").tag(1)            // tag is the value saved into option
                Text("MAC221").tag(2)
                Text("MAC250").tag(3)
            }
            .pickerStyle(WheelPickerStyle())
            Divider()
            Text("You selected option number \(option)")
        }
    }
}
StyleCodeLooks like
Menu (default in many places).pickerStyle(MenuPickerStyle()) or .menuA dropdown menu, saves space
Wheel.pickerStyle(WheelPickerStyle()) or .wheelA spinning wheel
Segmented.pickerStyle(SegmentedPickerStyle()) or .segmentedA bar of buttons across the screen
Inline.pickerStyle(.inline)All options listed in place
Navigation link.pickerStyle(.navigationLink) inside a NavigationView/FormTapping opens a new screen with the list

Pickers from a loop or an array

@State var option: String = "1"
Picker(selection: $option, label: Text("Picker")) {
    ForEach(1..<100) { number in
        Text("\(number)").tag("\(number)")    // tag is a String because option is a String
    }
}

@State var selected: String = "MAC101"
let courses: [String] = ["MAC101", "MAC108", "MAC196", "MAC221", "MAC250"]
Picker(selection: $selected, label: Text("Course options")) {
    ForEach(courses, id: \.self) { course in      // id: \.self because Strings aren't Identifiable
        Text(course).tag(course)
    }
}

Picker on another screen (@Binding)

The parent owns the @State; the child screen receives it as a @Binding, so a choice made on the second screen updates the first.

struct ContentView1: View {
    @State private var course = 1
    var body: some View {
        NavigationView {
            NavigationLink(destination: CourseListView(course: $course)) {
                Text("Select Course")
            }
        }
    }
}

struct CourseListView: View {
    @Binding var course: Int                    // not the owner, just a link
    var body: some View {
        Picker("Courses List", selection: $course) {
            Text("MAC220").tag(0)
            Text("MAC221").tag(1)
        }
        .pickerStyle(WheelPickerStyle())
        .navigationBarTitle("Select Course")
    }
}

Options can also be grouped with Section(header: Text("Mathematics")) { ... } inside the Picker.

DatePicker

A date picker lets the user pick a date (or time) from a calendar-style control. It binds to a Date.

struct ContentView5: View {
    @State private var selectedDate = Date()        // Date() = right now

    var body: some View {
        VStack {
            Text("Selected Date: \(selectedDate, formatter: dateFormatter)")
            DatePicker("Select a Date",
                       selection: $selectedDate,
                       displayedComponents: .date)    // .date, .hourAndMinute, or both
                .datePickerStyle(WheelDatePickerStyle())
                .labelsHidden()                       // hide the "Select a Date" label
        }
    }

    private var dateFormatter: DateFormatter {
        let formatter = DateFormatter()
        formatter.dateStyle = .medium
        return formatter
    }
}
DatePicker styleLooks like
WheelDatePickerStyle()Spinning wheels for month, day, year
GraphicalDatePickerStyle()A full month calendar
CompactDatePickerStyle()A small date button that pops up a calendar
dateStyleExample output
.short1/1/22
.mediumJan 1, 2022
.longJanuary 1, 2022
.fullSaturday, January 1, 2022

ColorPicker("Pick a color", selection: $color) works the same way with a Color state variable.
