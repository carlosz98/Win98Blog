Linux Services

A service (daemon) runs in the background listening for requests; install its package with dnf, then control it with systemctl. The big ones are Samba, NFS, FTP, SSH and Apache.

Key concepts

  • Service = daemon, usually named with a trailing d: httpd, sshd, ftpd, nfsd.

  • dnf is Fedora's package manager since Fedora 22 (replaced yum). Each service comes from a package (sshd comes from openssh-server); install the package first.

  • systemctl actions: start, stop, restart, enable (start at boot), disable (don't start at boot), status.

(Ports for FTP, SSH and web are from the slides; Samba and NFS ports are the standard ones, added for reference.)

Samba

  • NetBIOS name daemon (nmbd) advertises the server's name to Windows. nmblookup tests name resolution.

  • Each Windows user needs a local Linux user; smbpasswd sets their Samba password.

  • testparm checks smb.conf syntax (the slide spells it "testparam"). Restart smb and nmb after editing.

  • From Windows: type \\servername in Run. From Linux: smbclient.

NFS

  • Server: install package, make the directory, add it to /etc/exports, run exportfs -a, restart NFS.

  • Client: showmount -e server lists shares, then mount it with type nfs; umount to disconnect.

FTP

  • vsftpd = Very Secure FTP daemon. Browser: ftp://user:password@server. Command line: ftp server.

SSH

  • SSH = Secure Shell (slide says "Secure Socket Shell"). Port 22.

  • The slide lists "enable" twice; the second step should be start.

Apache

  • Started as httpd. Each line in httpd.conf is a directive. Each request is a hit; a separate Apache daemon serves it, and the first daemon runs as root to start the rest.

Commands

dnf install openssh-server     # install a package
dnf list installed             # list installed packages
dnf update                     # update Fedora
systemctl start sshd.service   # start now
systemctl enable sshd.service  # start at every boot
systemctl status sshd          # is it running?
systemctl stop / restart / disable sshd
systemctl | grep sshd          # find one service in the list
ssh linux@192.168.1.10         # connect over SSH; exit or logout to leave
smbpasswd -a bob ; testparm ; smbclient //server/share -U bob
echo "/data *(rw)" >> /etc/exports ; exportfs -a
showmount -e server ; mount -t nfs server:/data /mnt/data
ftp server

Likely test points

  • Port numbers: FTP 20/21, SSH 22, HTTP 80, HTTPS 443.

  • Config files: smb.conf, /etc/exports, vsftpd.conf, sshd_config, httpd.conf.

  • enable vs start (boot vs now).

  • Apache document root /var/www/html and index.html.

  • Samba is for Windows, NFS for UNIX/Linux/Mac; exportfs -a, showmount.

  • get vs put, lcd vs cd.
