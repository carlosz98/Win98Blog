Part 1: The Unity interface and importing assets

Part 1 is about knowing which panel does what and how to get your own files into a project.

The four main panels

PanelWhat it showsWhat you do there
HierarchyEvery GameObject in the current scene, in parent-child orderAdd, duplicate, delete, rename and reorder objects; drag one onto another to make it a child
SceneA visual view of the scene (2D or 3D)Move, rotate and scale objects with the Hand, Move, Rotate and Scale tools; lay out the level
InspectorThe components and properties of the selected GameObjectChange position, rotation, scale and script variables; add or remove components; open scripts and materials
ProjectAll assets in the project (scripts, textures, models, prefabs), in foldersImport, organize and search assets; create C# scripts, materials and animations; drag assets into the Hierarchy or Scene

Five ways to add assets from your computer

  1. Drag and drop: open a folder in the Project panel (for example Assets/Images) and drag files in from File Explorer or Finder. Unity imports them automatically.

  2. Unity menu: Assets > Import New Asset..., pick the files, click Import.

  3. Right-click in the Project panel: right-click the target folder, choose Import New Asset..., pick the files, click Import.

  4. Copy into the project folder: paste files into the project's Assets folder on disk (for example Assets/Textures). Unity detects them when you switch back.

  5. Asset Store via Package Manager: Window > Package Manager, open the My Assets tab, sign in, then Download and Import.

Likely test points

  • Match each panel to its job. The Inspector edits the selected object; the Project panel holds assets; the Hierarchy holds what is in the scene.

  • Parent-child relationships are made by dragging in the Hierarchy.

  • Know at least the menu path Assets > Import New Asset... and Window > Package Manager > My Assets.

  • Assets copied straight into the Assets folder on disk are imported automatically.
