Part 2: Building the bird and the first script

Part 2 turns an empty object into a bird that falls with gravity and flaps when you press a key.

Components and what each one adds

ComponentHow to add itWhat it doesSettings to know
Empty GameObjectHierarchy right-click > Create Empty (or GameObject menu)Invisible container; groups objects; acts as a parentNone
Sprite RendererInspector > Add Component > Sprite Renderer, then drag an image into the Sprite fieldMakes the object visible as a 2D imageColor (tint), Flip X/Y, Sorting Layer (draw order)
Circle Collider 2DAdd Component > Circle Collider 2DCircular collision boundary (green outline in Scene)Good for balls, coins, the bird
Rigidbody 2DAdd Component > Rigidbody 2DPhysics: gravity and forces move the objectGravity Scale, Mass, Constraints (freeze rotation or position)

Together: the Empty GameObject is the base, the Sprite Renderer makes it visible, the collider gives it a physical edge, and the Rigidbody 2D makes it move.

Four ways to create a script

  1. Project panel: right-click a folder > Create > C# Script, name it (BirdScript), drag it onto the GameObject, double-click to open in Visual Studio or VS Code.

  2. Inspector: select the object > Add Component > New Script > name it > Create and Add. It is attached automatically; gear icon > Edit Script opens it.

  3. From the Hierarchy: create or right-click an object, then Add Component > New Script as above.

  4. Unity menu: Assets > Create > C# Script, then drag it onto the object.

The BirdScript

using UnityEngine;

public class BirdScript : MonoBehaviour
{
    public Rigidbody2D myRigidbody;
    public float flapStrength;

    void Start()
    {
        // runs once, before the first frame
    }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space) == true)
        {
            myRigidbody.velocity = Vector2.up * flapStrength;
        }
    }
}

  • using UnityEngine gives access to Unity features like physics, rendering and input.

  • MonoBehaviour is the base class that lets a script attach to a GameObject and receive Start() and Update().

  • public variables show up in the Inspector. You drag the bird's Rigidbody 2D into the myRigidbody slot there.

  • Start() runs once when the object is created or enabled. Update() runs every frame and holds most game logic.

  • Input.GetKeyDown(KeyCode.Space) is true only on the frame the key goes down.

  • Vector2.up is (0, 1). Multiplying by a number sets the speed.

  • The first version used a hardcoded 10. Swapping it for flapStrength lets you tune the jump in the Inspector without editing code. Changes made in Play Mode show immediately but are not saved when you stop.

Note: in Unity 6 the property is called linearVelocity; older versions (and the slides) use velocity.

Moving with other keys

public float moveSpeed;

if (Input.GetKeyDown(KeyCode.W)) myRigidbody.velocity = Vector2.up * flapStrength;
if (Input.GetKeyDown(KeyCode.S)) myRigidbody.velocity = Vector2.down * moveSpeed;
if (Input.GetKey(KeyCode.D)) myRigidbody.velocity = new Vector2(moveSpeed, myRigidbody.velocity.y);
if (Input.GetKey(KeyCode.A)) myRigidbody.velocity = new Vector2(-moveSpeed, myRigidbody.velocity.y);

A and D keep the current vertical speed (myRigidbody.velocity.y) so the bird still falls while moving sideways.

Likely test points

  • Which component makes an object visible (Sprite Renderer), which gives it a collision edge (collider), which gives it gravity (Rigidbody 2D).

  • What MonoBehaviour is for, and the difference between Start() (once) and Update() (every frame).

  • Why make a variable public (it appears in the Inspector and can be tuned without recompiling).

  • GetKeyDown vs GetKey: GetKeyDown fires once per press (good for a flap); GetKey is true every frame the key is held (good for steady movement).

  • What Vector2.up equals: (0, 1).
